0背景与目标
对照：纷享销客市场活动（类型 / 预算 / 预计成本 / 负责人）、Salesforce Campaign（Type / BudgetedCost / ExpectedResponse）、本仓库 SRS §3.14.9 / §3.14.12。 现状：新建活动仅名称、起止、渠道、目标、说明，栏位偏少；后端已有预算/花费/细分等未进新建表单。

本包目标（一句话）

让市场同学在新建活动时就能填齐策划必填信息；P0 优先「露出已有字段」，P1 补「活动类型 / 预期线索 / 地点」三个高价值栏位，不碰审批流与费用明细对象。

3字段规格

3.1 P0 — 露出已有字段（无迁移或极小改动）

字段来源必填UI说明
budget已有否金额输入≥0；与详情一致
currency已有否下拉，默认 CNY本包仅预置 CNY；可留扩展
owner_user_id已有否*负责人选择默认当前用户；可改派（需在权限范围内）
territory_id已有否地区选择可空
target_segment_id已有否客户细分选择挂现有 Segment 列表

* 服务端创建时仍兜底为当前用户；前端可显式选择。

3.2 P1 — 新增字段

字段类型必填说明
campaign_type String(30) NULL 否（建议选） 枚举：content 内容投放 · online 线上推广 · offline 线下活动 · exhibition 展会 · training 培训 · other 其他
expected_leads Integer NULL 否 预期线索数，≥0；用于列表/详情与实际线索数对比（只读 KPI，本包可先展示）
location String(200) NULL 否 活动地点（城市/场馆）；线下类优先展示

3.3 保留不动的现有字段

name* · status · start_at / end_at · channels（多选）· goal（文本）· description · campaign_number（自动）

7分期与验收

P0 表单对齐（约 1 人天）

  • 新建/编辑露出预算、币种、负责人、地区、细分
  • 详情编辑与新建字段一致
  • Schema 种子补 description/budget/currency
  • 手工：新建活动可保存上述字段并回读

P1 类型与目标（约 1～1.5 人天）

  • 迁移 089：type / expected_leads / location
  • 表单布局按类型显隐地点
  • 列表可选列：类型、预算；详情展示预期 vs 实际线索
  • 验收脚本可加轻量 API 用例

P2 后续（本包不做）

  • 活动审批流
  • 费用明细对象 / 核销
  • 按类型多布局 SOP
  • H5 编辑；新建时批量建渠道执行

P0 验收清单

  • 新建活动可填预算=10000、币种 CNY、负责人、细分并保存成功
  • 列表进入详情，字段与新建一致回显
  • 未填预算仍可保存（兼容旧数据）

P1 验收清单

  • 可选活动类型「线下活动」后出现地点栏，保存后回读
  • 预期线索=50，详情可见；实际线索仍为关联统计
  • 非法 campaign_type / 负预期线索返回 4xx
8明确不做
活动审批 / 费用明细与核销 / 社媒账号级 ROI 改造 / 按类型多套 SOP 模板 / 改渠道执行模型 / 强制预算或类型必填（本包保持可选，避免阻断存量习惯）/ 创作侧强制挂活动类型。
