## A. 商家 Web 联测

### FE-A21-01: 登录（联测）

**前置条件**:
- Web `5173`、API 已启；商家账号 seed 可用

**页面**: `/login`  
**将触发的 API**: `POST /auth/login`（body 含 `workspace_mode=merchant` 或等价）

**测试步骤（前端）**:
1. 打开登录页  
2. 输入手机、密码  
3. 确认商家/工作台入口（若有）  
4. 点登录  
5. Network 查看 login 请求  

**期望结果（双端）**:
- Network: **200**；返回 `access_token`  
- UI: 进入智营 `/dashboard`（未入驻则有入驻引导）；localStorage/cookie 有会话  
- 再用该会话打开需登录页不掉线  

**边界值测试**:

| 变体ID | 前端输入 | Network | UI |
|--------|----------|---------|-----|
| FE-A21-01-B1 | 密码错误 | 401 | 中文错误；无 token |
| FE-A21-01-B2 | 手机空 | 不发或 422 | 红字拦截 |
| FE-A21-01-B3 | 手机 10 位 | 422 | 格式提示 |

**业务场景测试**:

| 场景ID | 场景 | 操作 | 双端期望 |
|--------|------|------|----------|
| FE-A21-01-S1 | 登录后调商家 API | 打开 `/shop` 或入驻页 | 后续 GET 带 Authorization 且 200/按状态 |

**结果**: ☐

### FE-A22-01: 注册（联测）

**前置条件**: 未占用手机号

**页面**: `/register`  
**将触发的 API**: `POST /auth/register`（或项目注册路径）

**测试步骤（前端）**:

- 文案可见「注册≠入驻」类说明（若有）  

**边界值测试**:

| 变体ID | 前端输入 | Network | UI |
|--------|----------|---------|-----|
| FE-A22-01-B1 | 已注册手机 | 409/422 | 提示已注册 |
| FE-A22-01-B2 | 手机 10 位 | 422 | 红字 |

**结果**: ☐

### FE-A20-01: 入驻提交个人主体（联测）

**前置条件**: `MCH_NEW` 已登录；无 pending

**页面**: 入驻申请页（A20）  
**将触发的 API**: `POST /shop/onboarding/applications`（以落地为准）

**测试步骤（前端）**:
1. 打开入驻  
2. 选个人主体  
3. 填写姓名/店名/手机 `13900001111`/身份证  
4. 上传身份证正反面  
5. 点提交  
6. Network 确认 POST  

**期望结果（双端）**:
- Network: **201/200**；`status=pending`  
- UI: 成功提示；表单只读/「审核中」；无假商户号  
- 再 `GET /shop/onboarding/status`（或刷新）为 reviewing  

**边界值测试**:

| 变体ID | 前端输入 | Network | UI |
|--------|----------|---------|-----|
| FE-A20-01-B1 | 手机 12 位 | 422 或不发 | 红字；无新单 |
| FE-A20-01-B2 | 缺反面 | 422 | 提示补材料 |
| FE-A20-01-B3 | 已有 pending 再提交 | 409 | 冲突中文 |

**结果**: ☐

**业务场景测试**:

**结果**: ☐

## C. 买家端联测

### FE-M03-01: 详情购买到支付成功（联测）

**前置条件**: `SHOP_OK`；`SKU_COURSE` on_sale；Mock 支付；买家可登录

**页面**: M02→M03→M04→M05  
**将触发的 API**: 创建订单 → prepay →（Mock）支付结果/回调

**测试步骤（前端）**:
1. 首页点商品进详情，核对展示价  
2. 点立即购买（未登录则先 M01）  
3. 确认订单页提交  
4. Mock 支付成功  
5. 全程看 Network  

**期望结果（双端）**:
- Network: 下单 **201**；金额=服务端价（抓包改价无效）  
- Network: 支付成功后订单 paid；权益 active  
- UI: M05 成功；M06 已购可见；可进 M07/M08  

**边界值测试**:

| 变体ID | 前端操作 | Network | UI |
|--------|----------|---------|-----|
| FE-M03-01-B1 | 确认页连点提交 | 仅 1 单 | 按钮 loading |
| FE-M03-01-B2 | 支付取消 | 订单仍待付 | 可重新支付 |
| FE-M03-01-B3 | 店暂停仍打开购 | 422/拦截 | 暂停营业 |

**结果**: ☐
