## M0 · 认证与权限

### VS-1: 平台管理员登录

**前置条件**:
- 存在平台超管：手机号以 seed/主站为准（常用 `13800000000`）
- 密码与主站约定一致
- 可绑定平台商城角色

**API**: `POST /auth/login`  
**Headers**: `Content-Type: application/json`

**请求体**:
```json
{
  "phone": "13800000000",
  "password": "<约定密码>",
  "workspace_mode": "platform"
}
```

**期望结果**:
- HTTP 200
- `access_token` 非空；`token_type` 为 bearer（或项目约定）
- 后续带该 token 可访问 `/admin/shop/*`

**边界值测试**:

| 变体ID | 字段 | 输入值 | 边界类型 | 期望Status | 说明 |
|--------|------|--------|----------|------------|------|
| VS-1-B1 | phone | `""` | 空值 | 422 | 不能为空 |
| VS-1-B2 | phone | `1380000000`（10 位） | 格式 | 422 | 非法手机 |
| VS-1-B3 | phone | `138000000001`（12 位） | 格式 | 422 | 非法手机 |
| VS-1-B4 | password | `""` | 空值 | 422 | 不能为空 |
| VS-1-B5 | password | `wrongpass123` | 错密 | 401 | 中文失败 |
| VS-1-B6 | phone | 未注册号 | 不存在 | 401 | |
| VS-1-B7 | 请求体 | 缺 phone | 缺失 | 422 | |

**业务场景测试**:

| 场景ID | 场景 | 前置状态 | 操作 | 期望结果 |
|--------|------|----------|------|----------|
| VS-1-S1 | 正常登录 | 超管存在 | POST | 200 + token |
| VS-1-S2 | token 可用 | 已登录 | `GET /auth/me` | 200 |
| VS-1-S3 | 商家 workspace 错壳 | 仅平台身份强切 merchant（若无会员） | login/switch | 400/403 类拒绝 |

**结果**: ☐
