## 自动化跟批（与执行计划一致）

| 原则 | 说明 |
|------|------|
| 文档先定 | 本包 ID（`VS`/`VM`/`FE-*`）为权威；脚本跟文档 |
| 跟批启用 | 每批次落地后去掉对应 skip、补真断言；**禁止**等全部开发完再重生整套自动化 |
| 大改契约 | 改脚本并**回改本包**，禁止静默分叉 |
| UX | [26](./26-UX专家走查.md) 人工；不替代联测 |

细则见执行计划 **§0.4b**、**§2**。
