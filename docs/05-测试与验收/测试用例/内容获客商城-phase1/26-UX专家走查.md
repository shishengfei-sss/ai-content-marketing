**一致性**：商家顶栏 56、侧栏 200、主色 `#1677ff`。平台侧栏 220 与现网 Admin 一致。买家 CONS-07 未在多数页落地（白顶栏 + 店招蓝条）。

**操作习惯（最多 5）**：

1. 危险操作（暂停/清退）有二次确认与必填原因，符合 UX-USE-S1
2. 买家底栏已改为「首页 / 已购 / 我的」
3. 商品列表行操作在窄屏仍偏密
4. P02-D 恢复弹窗本轮未截到（筛选项被遮）
5. M14 直达领权链接对已核销 token 展示「链接无效」（错误态清晰）

**美观（最多 5）**：

1. 买家店招蓝渐变偏营销，与 CONS-07 不完全一致（非 P0）
2. 部分商品封面未加载（灰占位）
3. 无 emoji 堆 / 紫光；列表密度跟现网 CRM
