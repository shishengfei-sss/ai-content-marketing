## 1. 结论（一页看懂）

**低投入、平台自己当第一家商家，把业务流跑通；公域要通，但先不认证「能卖课的店」。**

- 课的履约放在 **自己的小程序 / H5**。
- 公域只验证：店能开、测试商品能付钱、订单能回流（能接真推送就接；接不了先 Mock）。
- **不报白教培、不做服务商、不代运营、不四条公域一起开。**

四条公域（方案已定顺序）：**抖音 → 视频号 → 快手 → 小红书**。Phase 1 代码只接了抖音 Stub 回调；另外三条尚未接。

**一句话：** 先开抖店（0 元试运营 + 服务测试品）验证「有店能成交」；系统内用 Mock 把领权上课跑通；没有软著时，真推送只优先视频号；卖课资格以后再说。

### 1.1 试跑怎么做

| 问题 | 结论 | 详见 |
|---|---|---|
| 谁当商家 | 平台公司自己，第一家 | §9 |
| 测什么商品 | **企业信息化咨询 · 15分钟远程答疑（测试）**，1～9.9 元；标题禁「课 / 培训」 | §5 |
| 抖店付钱走微信吗 | **不走**。买家在抖音付，抖店收到对公 | §8 |
| 软著 | 开店不要；**抖音订单推送要**；视频号商家自研不要 | §6 |
| 四公域 | 先开抖音；有余力开微信小店；快手 / 小红书先不开 | §7 |
| 保证金 | 新商常可 **0 元试运营**；出试运营后按 GMV 分档 500 / 2000 / 5000 | §4 |
| 执照能选什么 | 咨询 / 信息技术 / 软件；**不能选教培、不能选零售** | §3 |

### 1.2 现执照能卖什么（总表）

判定口诀：**一对多 + 系统教学 = 课（教培）；一对一 + 非标交付 = 咨询。**  
卖课：四条公域都要证，不是只有抖音。财务培训比 AI / 创业课更重；财务咨询也不等于代理记账。明细见 **§12**。

| 品类 | 现执照 | 试跑 |
|---|---|---|
| 信息化 / IT 咨询（抖店测试品） | **能** | **做这个** |
| AI 落地咨询、工具 / SaaS 订阅、对公内训 | **能**（不叫培训课） | 可做 |
| 企业管理咨询、诊断、陪跑 | **能** | 可做 |
| 预算绩效评价、票据信息咨询、财务制度梳理 | **能** | 可做 |
| 融资咨询（不荐具体产品） | 谨慎 | 可不碰 |
| AI 培训课 / 创业课 / 企业管理课 | **不能**（要教育培训 + 平台教培准入） | **不做** |
| 财务培训 / 会计考证课 | **不能**（教培 + 常要办学许可） | **不做** |
| 代理记账、报税代办、审计 | **不能**（要代账许可 / 事务所证） | **不做** |
| 实物零售、虚拟充值、中小学学科 | **不能** | **不做** |

| | 开店、上测试商品、内部买一单 | 订单自动进本系统（Webhook） |
|---|---|---|
| 要不要教培白名单 | **不要**（测试商品不要写成课） | 不要 |
| 要不要软著 | **不要** | **看平台**（见 §6） |
| 要不要打通微信支付 | **抖店不要**（见 §8） | 不要（回流走店铺订单推送，不是微信支付回调） |

执照没有「教育培训」，也没有零售，**开不出教培店，也开不出日用百货店**。能对上的是咨询 / 信息技术 / 软件服务。

## 3. 这份经营范围能选什么

执照核心：信息技术咨询、软件开发、数据处理、企业管理咨询、信息咨询、互联网信息服务等。

| 类目 | 能不能选 |
|---|---|
| 教育培训 / 知识付费 / 在线课 | **不能**（执照没有 + 平台定向邀约） |
| 日用、服饰、食品等实物 | **不能**（没有零售，超范围） |
| 咨询、信息技术、软件相关服务 | **可以试** |
| 虚拟充值、游戏、会员 | 基本不行（定向 + 额外许可） |

「互联网信息服务」只是经营范围用词，**不等于已有 ICP 许可证**。选软件 / 虚拟类目时，后台常会要 ICP 备案截图。

## 4. 抖店保证金（以入驻页为准）

2025 年 6 月后，抖店基础保证金 **按销售额分档，不再按类目**。新商可 **0 元入驻试运营**。

| 阶段 | 大概要缴 |
|---|---|
| 刚开店、内部试跑几单 | **0 元**（发品数、提现、活动有限制） |
| 出试运营后（约 200 单或累计 1 万） | **500 / 2000 / 5000**（看上月 GMV：&lt;5 万 / 5～10 万 / ≥10 万） |
| 被判高退赔或特殊类目 | 另加体验保证金（普通约基础×2，高风险约×10；0 元入驻时基础按 500 算） |

内部只买几单，通常一直是 0。应缴额以 [抖店企业入驻](https://fxg.jinritemai.com/h5/enter?shop_type=11) 页面为准。

## 5. 测试商品（抖店探针）

选 **一次性咨询 / 诊断服务**，不要选课、不要选货。价格 **9.9 元以内**，只给内部买，用来打通「付钱 → 出单」。

### 5.1 首选（只上这一个）

| 项 | 内容 |
|---|---|
| 名称 | 企业信息化咨询 · 15分钟远程答疑（测试） |
| 卖的是 | 约一次远程沟通，口头答疑，结束后给一页文字结论 |
| 价格 | 1.00 或 9.90 |
| 发货 | 无需物流；详情写「下单后 1 个工作日内企业微信/电话联系」；可用卡密写「已受理，凭订单号预约」 |
| 库存 | 10 件 |

买的人是同事，须 **真打一次电话或发一页结论**，避免空单被判虚假交易。

### 5.2 备选（首选类目选不了时，二选一）

| 商品 | 适合执照 | 交付物 |
|---|---|---|
| 小程序/网站体验问题诊断（1页书面结论） | 信息技术咨询 | PDF / 文档链接 |
| 软件接口联调预评估（30分钟） | 软件开发 / 技术咨询 | 预约一次 + 结论纪要 |

### 5.3 标题和详情禁止出现

课、课程、网课、培训、教程、训练营、知识付费、专栏、听课、学习、课件、试听。

也不要上：实物、优惠券礼包、充值、会员月卡、电子书当课、资料包当课。

### 5.4 上架注意

1. 类目跟商品一致：咨询 / 信息技术 / 软件服务。
2. 主图用公司 / 咨询场景，不要用教室、黑板、讲师。
3. 可写「内部测试商品，不对外销售」（减少误审，但不能当免责）。
4. 只内部下单：不挂橱窗、不投流、不直播推。
5. 单价 &lt; 10 元，虚拟 / 服务类审核通常更快。

## 6. 软著：开店不要，抖音推送要

当前 **没有软著**。

| 平台 | 开店 | 订单推到自己系统 |
|---|---|---|
| **抖音** | 不要 | **要**。自用型应用强制软著，且著作权人 = 开发者公司 = 开店公司 |
| **视频号 / 微信小店** | 不要 | **不要**。商家自研：小店后台「服务市场 → 经营工具 → 自研」拿 AppID，配消息推送 |
| **快手** | 不要 | **多半要**（自用型审核常要软著，以创建页为准） |
| **小红书** | 不要 | **商家自研不要**（须企业店且正常经营；个人 / 个体不行） |

没有软著时：抖店可以先开、先成交，回调先 Mock；真推送优先走 **视频号**。  
软著可并行办：执照已有软件开发，自己在版权中心登记或走代理，普通约 1～2 个月。不要买来路不明的证。

## 7. 四条公域（试跑口径）

**共同规则：** 选咨询 / 软件 / 商业服务，不要选课、不要选货；测试商品几块钱、不要写成课程；对外先不要用这条卖真课。

### 7.1 抖音（方案默认 · Phase 1 已有 Stub）

1. 打开 [抖店企业入驻](https://fxg.jinritemai.com/h5/enter?shop_type=11)，主体选企业。
2. 类目只选和「企业管理咨询 / 信息技术咨询 / 软件开发」对得上的。
3. 能勾「0 元入驻」就勾；页面上的「应缴保证金」才是准数。
4. 店里上 §5 测试商品，内部买一单。

**没有软著：店和钱可以有，官方 Webhook 配不上。**  
现有接口是自有 Stub 验签，还不是抖店 `tag / msg_id / data`；真推送还要改代码。  
教培报白、教培保证金、服务商代办：试跑不做（见启动计划 HTML）。

### 7.2 视频号 / 微信小店（没有软著时最值得试）

- 和私域同属微信，对接比抖店少一道。
- 开企业小店，类目选咨询 / 商业服务，不要选教育培训。
- 自研回调 **不要求软著**。
- 教培仍是定向 / 品牌旗舰，同样卖不了课。
- **代码未接**，要新做微信小店支付 / 订单回调。

### 7.3 快手

- 开店可以；教培 / 虚拟多为定向。
- 泛知识小程序还要课程库，低 GMV 保证金约 **2000**，研发更重。
- 自用型推送和抖音类似，没软著先别赌。
- **代码未接。** 试跑阶段先不开。

### 7.4 小红书

- 企业店 + 千帆可经营；商家自研不强制软著。
- 原生「专栏」卖课多为邀约；笔记导微信容易违规。
- 产品里目前只是 **内容导出**，没有店铺订单回流。
- **代码未接。** 试跑阶段先不开。

### 7.5 对照总表

| | 开店要软著？ | 订单推送要软著？ | 用这份执照试跑 | 保证金（试跑量级） |
|---|---|---|---|---|
| 抖音 | 不要 | **要** | 咨询 / 软件类目可以开店，不能卖课 | 新商常可 0 元试运营 |
| 视频号 / 微信小店 | 不要 | **不要** | 选咨询 / 商业服务，不要选教培 | 入驻页为准，普通类目常见千元级 |
| 快手 | 不要 | **多半要** | 咨询类可试；教培定向 | 小店按类目；泛知识小程序低 GMV 约 2000 |
| 小红书 | 不要 | 商家自研不要 | 企业店选咨询 / 数字服务 | 企业店按类目，常见千～万元 |

## 8. 测试商品付钱要不要跟微信打通

**抖店里的测试商品：不要。** 走抖店收款，不是本系统小程序那套微信支付。

| 在哪付钱 | 要不要跟微信打通 | 实际走什么 |
|---|---|---|
| **抖店测试商品**（公域探针） | **不要** | 买家在抖音里付；店入驻时绑 **对公账户**，抖店统一收、再结算到对公。不用申请微信支付商户号，也不用接服务商进件 |
| **微信小店 / 视频号** | 要，但是小店自己的 | 开店流程里开通微信支付收款，和本系统「小程序 JSAPI / 服务商进件」不是同一套 |
| **本系统小程序 / H5 卖课**（私域） | **要**（试跑可用 Mock） | 才是平台通道配置 / 商家进件那套微信支付 |

本系统要收到抖店这一单，靠的是 **抖店订单推送**（没有软著就先 Mock / 手工领权），也不是微信支付回调。

只有要在 **自己的小程序里真收款**，或走 **视频号小店** 时，才需要碰微信。试跑私域可以继续用 Mock 支付，不挡「上架 → 开权 → 上课 → 退款」。

## 9. 建议动作（按顺序）

### 9.1 本周商务

1. 开 **抖店企业店**（咨询 / 软件类目，0 元试运营）。
2. 上 §5 测试商品，内部买一单并真实履约一次。
3. 有余力再开 **微信小店**（同样不要选教培）。
4. 同时去登记 **软著**（为以后抖音真推送）。
5. 快手、小红书店铺先不开。

### 9.2 本周产品 / 研发（系统内先跑通）

1. 平台公司 = 商家 001：入驻 → 审过 → 上 1 门课 → 可售。
2. 测试买家：小程序 / H5 下单 → Mock 付成功 → 能上课。
3. 退一笔：课立刻学不了。
4. 公域形态：绑假店铺号 / Mock Webhook → 领权 → 上课（不依赖真抖店推送）。

### 9.3 软著下来之后

- 建抖店自用型应用，把 Stub 回调改成真实抖店推送。
- 若视频号店已开，再接微信小店订单回调。

## 10. 明确不做

- 教培定向邀约、办学许可、教培保证金、认证服务商代办报白（那是启动计划 HTML 的主路径）
- 代开发 / 代运营服务商
- 用书籍、电子资料、私信加微信绕过教培
- 每个客户各自开店、各自报白
- 四条公域同时投入
- 把「Phase 1 完成」绑在抖音真卖课首单上
- 在现有执照下公域上架「AI 培训课 / 创业课 / 企业管理课 / 财务培训课」或做代理记账 / 报税代办（见 §12）

## 11. 口径备忘

- 2026-01-21 起抖音「教育培训」全量定向邀约，无公开自助入口；咨询电话 950529。
- 抖店新商 0 元入驻、基础保证金按 GMV 分档：见 [抖店入驻资费](https://fxg.jinritemai.com/question/fee)。

- 微信小店商家自研不强制软著：见 [开发者使用指南](https://developers.weixin.qq.com/doc/store/shop/dev_before/guide.html)。
- 类目与应缴保证金 **以各平台入驻页实时显示为准**；本文数字为公开口径整理，供决策，不作缴费凭证。
- 微信小店教培准入（含创业知识、财务/会计培训）：[一级类目-教育培训准入标准](https://store.weixin.qq.com/chengzhang/webdoc/wiki/7502/f354e4d710f63814/growth_center_rule_for_store)。创业理财禁止成功学 / 荐股；财务 / 会计培训与考研、司法考试同组资格证类目，线下要办学许可（或民非 / 事业单位证）。
- 代理记账须持《代理记账许可证书》（财政部令第 98 号）；审计须会计师事务所执业证书。执照有「企业管理咨询」不等于可代账报税。

## 12. 卖课资质汇总（教培 / AI / 创业·管理 / 财务）

**判定口诀：一对多 + 系统教学 = 卖课（教培）；一对一 + 非标交付 = 服务（咨询）。**

执照核心是信息技术咨询、企业管理咨询、软件开发，**没有教育培训**，也 **没有代理记账**。公域挂「课 / 培训 / 训练营」，四条线都过不了第一关。

### 12.0 品类总对照

| 品类 | 算不算课 | 办学许可 | 还要什么 | 现执照 | 试跑 |
|---|---|---|---|---|---|
| 信息化 / IT 咨询（测试品） | 否 | 不要 | — | **对得上** | **做这个** |
| AI 落地咨询 / 工具订阅 / 对公内训 | 否 | 不要 | 生成式 AI 对外服务另看算法备案 | **对得上** | 可做 |
| 企业管理咨询 / 诊断 / 陪跑 | 否 | 不要 | — | **对得上** | 可做 |
| 预算绩效评价 / 票据信息咨询 / 财务制度梳理 | 否 | 不要 | — | **对得上** | 可做 |
| 融资咨询（不荐产品） | 否 | 不要 | 不要做成投资建议 | 有融资咨询；不含金融信息服务 | 谨慎 |
| AI 培训课 | **算** | 一般不要 | 执照含培训 + ICP + 讲师证 + 四平台教培准入 | 对不上 | **不做** |
| 创业课 / 企业管理课 | **算** | 一般不要 | 同上；禁成功学 / 荐股 / 承诺月入 | 对不上（咨询≠培训） | **不做** |
| 财务培训 / 会计考证课 | **算** | **常要**（线下必要；线上考证班风险高于 AI / 创业） | ICP + 讲师会计 / CPA / 税务师 | 对不上 | **不做** |
| 代理记账 / 报税代办 | 否（服务） | — | **《代理记账许可证书》** | 没有 | **不做** |
| 审计 / 验资 | 否（服务） | — | 会计师事务所执业证书 | 没有 | **不做** |

以后要卖课：先变更经营范围加上培训 → ICP → 讲师证 → 再申请各平台教培；财务 / 会计课额外准备办学许可。AI / 创业 / 管理课办学许可多数可后置。

### 12.1 除抖音外，教培卖课也要资质

不是「只有抖音要证」。一层是国家规定（换 App 不变），一层是各平台类目准入。

**法定（四条公域都一样）**

| 情况 | 通常要什么 |
|---|---|
| 线上课 | 执照含教育 / 培训；线上交付常要 **ICP 备案**（主体一致） |
| 学科、语言、考研、学历类等 | 很多还要 **办学许可证**，或与持证机构签一级合作授权 |
| 面向中小学学科 | **全面禁售** |
| 讲师 | 按类目交教师资格证 / 职业资格 / 学历 |

**各平台额外门槛**

| 平台 | 能不能自己点开教培 | 常见还要交的 |
|---|---|---|
| **抖音** | 2026.1.21 起全量 **定向邀约** | 企业、注册资本、师资、课程材料、保证金 |
| **视频号 / 微信小店** | 按子类目交材料；部分仍 **定向** | 《产品经营说明书》+ **ICP 或增值电信许可证**；部分类目要办学许可或旗舰店背书 |
| **快手** | 小店教培多为 **邀请制**；泛知识小程序定向 + 课程库 | 执照含培训、办学 / 教师证、课程审核 |
| **小红书** | 店铺教培要 **报白**；「专栏」多为 **邀约** | 企业 / 专业号、行业选对；学历语言等还要企业号 |

更轻、但 **不算自己开教培店卖课** 的路径：分销别人已报白的课；公域内容 + 私域成交（广告法、禁导流仍在）；不叫课、叫咨询。

### 12.2 AI 培训

只要当「课」卖，一样算教培，多落在 **职业技能 / IT·编程·计算机** 或办公技能。抖音全量子类目邀约，**AI 课没有豁免**。

| 卖法 | 算不算教培 | 和现在执照 |
|---|---|---|
| 录播课、训练营、小黄车「AI 培训」 | **算** | 对不上，要先改经营范围 |
| 一对一「AI 落地咨询 / 诊断」 | 咨询服务 | **对得上** |
| 卖 AI 工具 / SaaS 订阅（不教课） | 卖软件 | **对得上** |
| 对公企业内训（合同） | 不走小黄车 | 咨询 / 技术服务可做 |

职业技能 / IT 类通常 **不强制办学许可**（考证班、线下班另说），但仍要：执照含培训、ICP、讲师计算机相关证明、各平台教培准入。

AI 课额外红线：不承诺学完接单月入 / 保就业；不教 AI 换脸仿声赚钱；不打着 AI 课卖带货培训或站外导流。自己对外提供生成式 AI 能力是 **算法备案**，和卖课资质是另一件事。

### 12.3 创业、企业管理类培训

公域上架「创业课 / 管理课」仍是教培。微信小店多在 **教育培训 → 创业理财 → 创业知识**：要说明书 + ICP，**一般不要办学许可**。

| 卖法 | 平台类目 | 算不算教培 |
|---|---|---|
| 录播课 / 训练营 / 小黄车「创业课」「管理课」 | 创业理财 / 职业技能 / 商业管理 | **算** |
| 一对一企业管理咨询、诊断、陪跑 | 咨询 / 商业服务 | **不算课** |
| 对公企业内训、工作坊 | 商务合同 | **不算店铺教培** |

执照里的「企业管理咨询、咨询策划、融资咨询」适合 **卖咨询**，不适合直接开「创业培训」类目。

这类课内容红线比 AI 更紧（视频号明确禁止）：荐股 / 荐基金 / 荐房 / 荐信贷；教避税套现；传销式、成功学、洗脑式创业课；承诺月入过万、保创业成功、保证涨薪。有融资咨询也不要在课里做具体投资建议，否则会往金融资质上靠。

### 12.4 财务咨询、财务培训

财务 **培训** 和财务 **咨询** 不是同一档。培训按教培（且常按考证类）管，比 AI / 创业课更重；咨询若做成记账、报税代办，还要 **代理记账许可 / 事务所资质**，现有执照也不够。

**财务培训课（公域上架）**

微信小店把 **财务 / 会计培训** 和考研、司法考试、教师资格培训放在同一组「学历资格 / 资格证考试」三级类目：

| 项 | 口径 |
|---|---|
| 类目 | 教育培训 → 学历资格 / 职业技能 → 财务 / 会计培训 |
| 抖音等四平台 | 仍是教培，要邀约 / 报白；无豁免 |
| 办学许可 | **线下必要**（或民非 / 事业单位证）；线上考证班也常按资格证类管，被要办学许可的风险 **高于** AI / 创业课 |
| 讲师 | 会计职称 / CPA / 税务师等 |
| 执照 | 要含教育培训；现有「企业管理咨询」不够 |
| 红线 | 不保过、不承诺通过率、不教偷税漏税 / 虚开发票 |

Excel 财务表、报销流程如果打成「办公技能 / 实操指南」且不碰考证，有时能靠办公类；**商品名写成财务培训、会计考证、报税班，就会进财务 / 会计培训。**

**财务咨询（服务，不是课）**

| 卖法 | 还要什么 | 和现在执照 |
|---|---|---|
| 财政资金预算绩效评价、票据信息咨询、企业管理里的财务制度梳理 | 对得上已有经营范围 | **可做**（一对一 / 对公合同） |
| 融资咨询（不荐具体产品） | 执照有融资咨询；不要做成投资建议 | 谨慎可做 |
| 代理记账、报税代办、出账 | **《代理记账许可证书》**；执照还要有代理记账 | **不能做** |
| 审计、验资 | **会计师事务所执业证书** | **不能做** |
| 税务代理 | 税务师事务所登记等 | **不能做** |

执照写了「不含金融信息服务」，公域不要卖财商课、荐基荐股、信贷中介。

### 12.5 现在就做 / 不要做 / 以后

总表见上文 **§1.2** 与 **§12.0**。

**现在就做：** 抖店咨询测试品（§5）；企业管理咨询、信息化 / AI 落地诊断、预算绩效评价 / 票据信息咨询、对公内训合同。  
**不要做：** 公域上架 AI / 创业 / 管理 / 财务培训课；代理记账、报税代办、审计；荐股荐基、教避税。  
**以后要卖课：** 先变更经营范围加上培训 → ICP → 讲师证 → 再申请教培；财务 / 会计课额外准备办学许可（尤其线下或考证班）。AI / 创业 / 管理课办学许可多数可后置。
