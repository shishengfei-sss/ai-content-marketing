## 0. 执行规则（沿用项目惯例）

1. **一步一验**：顺序执行 Step，每步专项验收 + 回归门禁 PASS 才进下一步。
2. **回归门禁**：每步跑 `apps/api/tests/run_crm_all.py --through <最新已验收阶段>` 与 `run_agent_a_c.py` 全绿。
3. **Confirm 闸优先**：任何写 CRM / 对外动作必须先 propose，人 confirm 才执行（沿用 BR-01、v0.4 C3）。
4. **不破坏现有**：每步跑 `run_m0_m8.py` 与 `run_agent_a_c.py` 回归。
5. **可解释 + 溯源**：子 Agent 所有结论带数据来源；无依据答"资料库未覆盖"。

## 1. 总体设计

### 1.1 角色映射（Supervisor + 子 Agent）

| 角色 | 复用/新增 | 说明 |
|------|-----------|------|
| `SalesManagerSupervisor` | 新增（封装 v0.4 C5） | 销售经理大脑：意图理解 → 拆解 → 派发 → 汇总解释 → 闸控 |
| `AnalystAgent`（分析官） | 新增 | 基于 v1.2 报表：预测/赢单率/差距/看板问答 |
| `OpportunityAgent`（商机官） | 新增 | 商机推进策略、停滞预警、下一步行动（读商机 + 线索库相似案例） |
| `ContentAgent`（内容官） | **复用 v0.6 营销顾问** | 扩展：复盘报告/方案提案/对客话术，带溯源 |
| （占位）线索官/客户官/报价官/教练官/协同官 | 注册接口，Phase 3 点亮 | Supervisor 预留调度槽位 |

### 1.2 销售经理人格（人格库新增条目）

在人格库新增"稳定人格 + 镜像变体"，不写进提示词正文（遵循人格库手册 §8.3）：

```
人格编号：P-MGR（稳定人格）
人格名称：资深销售经理
核心价值观：目标感 / 决断 / 可解释 / 守边界（不擅自对外承诺）
行为边界：发邮件·对外报价·改分配 → 必须人确认；内部分析可自动
镜像策略：对团队成员→教练式推进；对客沟通→复用 P-001~P-009 镜像反射
禁用表达："我替你决定了""已经帮你发了"（未经确认）
```

### 1.3 调度骨架（基于 v0.4 C5 Supervisor）

- `orchestrator.py` 新增 `SalesManagerSupervisor`：识别意图 → 选择子 Agent → 汇聚多 Agent 结果 → 生成带"为什么"的总结 → 危险动作插入 Confirm 闸。
- 子 Agent 以"工具/Worker"形式注册到 Supervisor 的 dispatch 表，新增 Agent 只需登记，不改调度核心。

## 3. Phase 2 · MVP 三子 Agent

### 3.1 分析官（AnalystAgent，约 1–1.5 周）

| Step | 任务 | 关键文件 | 验收 |
|------|------|----------|------|
| A1 | 封装 v1.2 报表为分析工具（预测/赢单率/差距/看板） | `analytics` 服务 + 工具注册 | 工具可被 Agent 调用 |
| A2 | 可解释输出模板（结论→依据→建议） | 提示词 | 回答含数据来源与推理 |
| A3 | 对话问答：差距分析/补单建议 | 测试 | "本季能完成吗、差多少、怎么补"可答 |

### 3.2 商机官（OpportunityAgent，约 1–1.5 周）

| Step | 任务 | 关键文件 | 验收 |
|------|------|----------|------|
| O1 | 读商机 + 线索库相似成交案例 RAG | RAG（C4）+ 线索库 API | 能召回相似案例并溯源 |
| O2 | 阶段推进策略 + 停滞预警 + 下一步行动 | 提示词 + 规则 | 对具体商机给可解释建议 |
| O3 | 高风险动作走 Confirm 闸（如"标记为推进"） | C3 闸 | 写操作需 confirm |

### 3.3 内容官（ContentAgent，复用 v0.6，约 1 周）

| Step | 任务 | 关键文件 | 验收 |
|------|------|----------|------|
| C1 | 复用 v0.6 营销顾问，扩展模板：复盘报告/方案提案/对客话术 | `assistant_service.py` + 模板 | 三类模板可生成 |
| C2 | 生成带溯源（引用营销库/线索库） | RAG | 输出含引用锚点 |
| C3 | 提交前需人确认（复用发布闸） | C3 | 未 confirm 不落库/不发出 |

**P2 门禁**：`verify_salesmgr_p2.py` 全 PASS + 回归全绿。

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
