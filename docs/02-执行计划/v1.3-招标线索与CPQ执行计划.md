## 4. 数据模型要点（实现参考）

**新建：** `platform_tender_leads`（含 **`source_url` 原文链接**，有则必填并持久化）、`tender_attachments`、`parse_jobs`、`scored_tender_leads`、`icp_configs`、`product_params`、`param_pricings`；PDF 可挂 `quotes` 或 `quote_pdfs`（FK→`quotes.id`）。

**L1 原文链接：** 手工/Excel/附件 AI 确认入库均写入 `platform_tender_leads.source_url`；租户 L2 详情只读展示，可新开页打开。

**扩展：** `products.cpq_enabled`；`quotes.cpq_config_snapshot`；可选 `quotes.related_tender_lead_id`。

**禁止：** `crawler_*` / `raw_contents`；以 `quote_histories` 替代 `quotes` 作为销售主单据；租户写 L1。

## 5. 风险与应对

| 风险 | 应对 |
|------|------|
| 租户配不齐参数 | 先 2～3 个标准产品模板 + Excel 导入参数 |
| 平台运营入库跟不上 | Excel 批量 + 附件 AI 提效；先保试点样本 |
| 附件 AI 抽字段不准 | 强制人审；失败转手工 |
| 线索噪音高 | 严 ICP；初期每周 top N |
| 与主线争人 | W1–6 只做 CPQ |
