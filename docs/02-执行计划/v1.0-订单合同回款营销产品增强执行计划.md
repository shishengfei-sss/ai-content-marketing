## 0. 范围与决策

### 0.1 现状校验（20 项）

见 r2 表（略）。关键边界：

- **跳过**：折扣字段、channels 改 JSON、Lead.campaign_id 新建、独立 lines/payment-progress API  
- **P0**：审批、税率、四 Tab、模板/附件、分类、高级查询/列设置、H5 可达与订单操作  
- **P1**：发货/发票/修订、WEB PaymentDetail/ProductDetail、应收退款、ROI/SKU  

### 0.2 关键决策

| 决策 | 选择 |
|------|------|
| 无审批规则 | `confirm` 仍可直接 → confirmed |
| 有规则 | `submit` → pending_approval → approve → confirmed |
| 审批权限 | 新权限码 `crm.order.approve`（sales_manager / admin） |
| 税率 | `tax_rate`/`tax_amount`；`line_total` 仍为折后未税合计；展示含税 = 前端或 `line_total_incl_tax` 计算 |
| Tab P0 | 仅 基本 / 明细 / 审批 / 回款 |
| WEB 独立详情 | PaymentDetail / ProductDetail → **P1** |
