## 0. 范围与决策

### 0.1 三类交付（用户诉求）

1. **规格型号** — 独立基础数据字典 + 产品主档关联  
2. **字段可自定义** — Schema 设置页 + 产品表单/详情接通 `extra_data`  
3. **导入** — Web 产品列表批量导入（复用线索导入框架）

### 0.2 关键决策（与 PRD / SRS 对齐）

| 决策 | 选择 |
|------|------|
| 规格型号模型 | 字典表 `product_spec_models` + `products.spec_model_id`；**不做**属性矩阵 SKU |
| Schema | 复用 §3.15；仅打通前端（SettingsSchema + Products + ProductDetail） |
| 导入 | `IMPORT_ENTITY_TYPES` += `product`；去重键 `code`；引用列按名称解析 |
| 端 | P0 **仅 Web**；H5 规格展示为 P1 |
| 不做 | 变体/价目导入、库存 BOM、表单设计器、改 CPQ 参数体系 |

### 0.3 现状校验（实施前再跑一遍）

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | `SettingsProductMasterData` | 仅分类 + 单位 Tab |
| 2 | `SettingsSchema.ENTITY_TABS` | 无 product |
| 3 | `IMPORT_ENTITY_TYPES` | 仅 lead/customer |
| 4 | `PRODUCT_FIELDS` 种子 | 无 `spec_model_id` |
| 5 | Products 表单 | 写死字段，无 `extra_data` |
