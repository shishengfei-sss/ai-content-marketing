本包解决的三类用户诉求

  1. 产品要标默认税 — 维护默认税率与「标价是否含税」，选入报价/订单自动带入，减少手工填税。
  2. 报价要看清价税 — 行级税率、税额、未税小计、含税小计；整单未税合计 / 税额合计 / 价税合计。
  3. 转单不断税 — 报价转订单、合同路径尽量透传税字段，与订单 v1.0 公式一致，避免二次录入。

4计算与精度（行级独立 + 尾差兜底）
P0 硬规则（产品决议）：每行商品独立计算并四舍五入到分 → 再求和 → 自动校验「总未税 + 总税额 = 价税合计」→ 若与精确税额差 0.01，系统把差额塞入最后一行商品的税额找平。

行级公式（每行独立）

# 入行单价（未税）——选品时
if product.price_includes_tax and tax_rate:
    unit_price = round(list_price / (1 + tax_rate/100), 2)
else:
    unit_price = list_price

# —— 每行独立 ——
# 行未税金额（有行折扣时先折再取整；无折扣即 单价×数量）
line_ex_tax = round(unit_price * quantity * (1 - (discount_rate or 0)/100), 2)

# 行税额：单行单独四舍五入到分
line_tax = round(line_ex_tax * (tax_rate or 0) / 100, 2)

# 行价税合计（不再二次 round）
line_incl_tax = line_ex_tax + line_tax

# 持久化：line_total = line_ex_tax；tax_amount = line_tax（可被尾差修正）

整单汇总与平衡校验

order_ex_tax   = sum(line_ex_tax)          # 总未税 → total_amount / amount
order_tax      = sum(line_tax)             # 总税额 → tax_total
order_incl_tax = order_ex_tax + order_tax  # 价税合计 → amount_incl_tax

# 自动校验（保存前后必须成立）：
assert order_ex_tax + order_tax == order_incl_tax

尾差自动兜底（P0）

# 「精确税额」定义：
# - 全单同一税率：exact_tax = round(order_ex_tax * tax_rate / 100, 2)
# - 多税率：exact_tax = round(sum(line_ex_tax_i * rate_i / 100), 2)
#   （中间项用更高精度，最后一次 round 到分；与「每行先 round 再加」对比）

delta = exact_tax - order_tax   # 通常为 -0.01 / 0 / +0.01

if abs(delta) == 0.01 and lines:
    last = lines[-1]   # sort_order 最后一行；优先有税率的行
    last.tax_amount = round(last.tax_amount + delta, 2)
    # 刷新：order_tax = sum(line_tax)；order_incl_tax = order_ex_tax + order_tax

# |delta| > 0.01：不静默多行分摊，记日志/告警；delta == 0：无需调整

精度硬决议

项规则
税率Numeric(5,2)，单位 %；校验 0≤x≤100
金额全部金额保留 2 位小数（分）；四舍五入
行未税round(未税单价 × 数量 [×(1−行折扣%)], 2)
行税额round(行未税 × 税率/100, 2) — 每行单独取整
行价税合计行未税 + 行税额（不二次 round）
整单总未税/总税额均为行求和；价税合计=二者之和
平衡恒等式：总未税 + 总税额 = 价税合计（保存时校验）
尾差±0.01 自动写入最后一行税额；属 P0
实现前后端同引擎；以服务端最终写入（含尾差）为准；推荐 Decimal
行折扣：有 discount_rate 时，行未税 = round(未税单价×数量×(1−折扣%/100), 2)，仍满足「先得行未税再算行税」。 头折扣（锁定）：按行未税占比摊入 → 末行吃未税分摊尾差使 Σ=round(Σ×(1−头折%),2) → 再算行税与税额尾差。 禁止只减总未税而保留原行税。实现见 tax_engine.compute_tax_lines(..., header_discount_rate=)。

7业务规则
ID规则
BR-TAX-01每行：行未税=round(未税单价×数量[×折],2)；行税=round(行未税×税率/100,2)；行价税=行未税+行税

9明确不做（本包）
  • 订单与报价共用本包价税引擎（含尾差）；允许改造订单保存路径以对齐，不另起公式
  • 不建独立税码/税组主数据表（P0）
  • 不做运费单独计税、价外费用税拆分
  • 不做合同行独立税模型（若合同无明细价税则本包不扩）
  • 不做红冲/专票勾稽规则（属发票域）
  • 不改成本价毛利公式为「税后毛利」（P2 可评估）
