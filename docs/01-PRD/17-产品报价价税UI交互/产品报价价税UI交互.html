0UX 原则与主流程
一套公式，两端一致报价与订单共用行级价税引擎（含尾差）；列文案一致：税率% / 税额 / 未税小计 / 含税。
行独立取整每行先算未税再算税额，各自四舍五入到分，再求和；禁止用整单×税率代替行税。
平衡可见汇总区恒满足「未税合计 + 税额合计 = 价税合计」；尾差 ±0.01 时静默调整最后一行税额（不弹窗打断）。
标价只存一套产品只编一个标价 + 是否含税；参考换算只读；选品带入默认税率可改。

销售主路径 UX

1. 配产品税
产品新建填默认税率 + 标价是否含税
2. 建报价
选品 → 自动带税率与未税单价 → 可改折扣/税率
3. 看清价税
底部三合计；详情头展示含税金额
4. 转订单
税字段透传；订单详情与报价一致
文案统一：用「未税 / 含税 / 价税合计」，避免「税前价/税后价」混用；税率列标题固定「税率%」。
