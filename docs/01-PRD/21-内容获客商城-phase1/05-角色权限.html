平台运营端角色（跨租户）

挂接智营 platform_admin，入口 /admin。权限前缀 platform.shop.*，不参与企业 Membership，无 tenant_id 上下文。

角色权限范围页面典型使用者
platform_admin 全部 platform.shop.* + 主站租户/账号管理 P01–P12平台运营负责人
platform_shop_ops（子角色，Phase 1 可选） 入驻审核（P08 可拆分绑定）、暂停恢复、商品审核、稽查；无清结算写权限；不含发起入驻（归商家管家）、套餐模板 P10、订阅开通 P11 P02–P03、P07、P09日常运营
platform_shop_cs（商家管家） 所辖客户入驻协助、续费跟进、服务记录；含 platform.shop.merchant.read（查看与跟进写）；list_assigned 数据范围；无审核/暂停/P11 写 P02（我的客户）· P02-A · P02-B 只读客户成功 / BD

Phase 1 可先用单一 platform_admin 验收。运营账号与商城角色在智营主站 /admin/users 统一维护（P08-AU）；内置四角色说明见 P08-A。商家管家通过 account_manager_user_id 绑定所辖商家，P02 默认「我的客户」视图。

商家端默认角色（租户内）

挂接智营现有「角色与成员」体系（roles / role_permissions）。买家端无商家角色。新建租户时种子化 4 个店铺内置角色；企业管理员（admin）为系统内置，自动拥有全部 shop.*。

与 CRM 隔离：店铺角色只控制商家端 Web（A01–A23）；不授予 CRM Contact/商机权限。买家（shop_buyers）≠ Contact。
UI 入口：侧栏「设置」→ A-SET 设置中心 →「角色与成员」，见 A16。
角色 code显示名类型默认说明典型使用者
admin企业管理员系统 权限全开且不可削弱；含全部 shop.* + shop.role.manage老板 / IT
shop_admin店铺管理员店铺内置 店铺模块全功能（除改企业角色体系、租户级公域对接）；默认给运营负责人店长
shop_content内容运营店铺内置 商品/专栏/资料/服务定义与提交审核、上架；可看交易看板只读；不可退款/设置/公域配置写课程运营
shop_support客服店铺内置 订单/买家/权益/开票处理；退款审核、重发短信；不可改商品与店铺设置售后客服
shop_clerk店员店铺内置 仅核销台（A08）；可执行核销、查码；不可浏览订单列表与财务门店店员
Phase 1 不支持自定义角色增删（仅启用/禁用内置角色、改成员绑定）。自定义角色矩阵放 Phase 2。

数据维度权限

商家端：对齐 CRM 的 list_own / list_team / list_all 并集模型。平台端：商家列表按 list_all 或 list_assigned 过滤；未入驻 tenant 通过 shop_tenant_prospect_assignments 预分配管家（P02-E），P02-A 租户搜索与「我的客户」同源。

校验顺序（API）

  1. 租户上下文 tenant_id
  2. 功能权限（如 shop.order.refund）
  3. 数据范围并集（list_all ∪ list_own 条件）
  4. 敏感字段脱敏（买家手机号默认中间四位 *；平台端商家 contact_mobile / 个人 id_no 默认脱敏，👁 揭露走 reveal-sensitive + 审计）
店员角色：侧栏仅「核销台」；调用核销 API 需 shop.redemption.execute；列表 API 仅返回 list_own 核销记录（若开放历史页）。
