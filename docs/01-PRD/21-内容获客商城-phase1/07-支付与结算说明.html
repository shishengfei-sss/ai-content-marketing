模式一 · 平台代收 + P05 清结算（Phase 1 主路径）

私域买家小程序 M04 支付 → F1 回调开权。平台按 P04 类目费率记账，F10 周关账出批，财务 P05 人工打款。

详表：P05 结算规则 · PRD §2.5续

模式二 · 子商户直收 + 自动分账（路径 B · Phase 2）

平台 = 微信服务商，商家 = 子商户。买家付款进子商户，支付成功后系统调微信分账 API，按 P04 费率把平台份额划走。
