## 商家设置与角色

| 页面 | 作用域 | 内容 |
|------|--------|------|
| **A15** | 商家 tenant | 微信支付进件 · [**支付与结算说明**](./07-支付与结算说明.html) |
| **A15-S** | 商家 tenant | 短信签名/模板（只读）· 领权域名/过期天数 |
| **A23** | 商家 tenant | 公域对接（链路/绑店/Webhook） |
| **A18** | 商家 tenant | 套餐合并权益（只读） |
| **A19** | **当前店铺** shop_id | 本店展示、退款默认 |
| **A16** | 商家 tenant | 角色与成员（内置角色 · 成员绑定） |

多店时：A15/A15-S/A18/A16/A23 全商家共用；**A19 每家店各一套**，顶栏切店后编辑。  
设置顶栏五块并列：支付与进件 · 短信/领权 · 套餐信息 · 单店设置 · 角色与成员（**不含**公域对接；A23 从设置中心卡片进入）。侧栏「设置」→ [**A-SET 设置中心**](./01-管理端UI.html#a-settings)。

## 买家端独立规范

买家小程序（`02-买家端UI.html`）采用**独立于 Web 端**的视觉规范，与平台/商家端 `design-tokens.css` 对齐的浅色后台不同：

| 项 | 规范 |
|----|------|
| 顶栏背景 | `#0A1628` 深色 |
| 壳层 | `.phone` 手机框模拟小程序视口 |
| Tab 机制 | `.pdoc-tabs` + `.pdoc-panel`（与平台端 §2.5.1 L4 一致；买家端保留独立配色） |
| 线框 | 四张规格表齐全；M01–M15 已补 L1 优先级标签 + L3 鉴权摘要（链 §六 权限） |

详见 [02-买家端UI.html](./02-买家端UI.html) · [PRD §3 买家端](./PRD-内容获客商城-phase1.md#三买家端小程序-m01m15)。
