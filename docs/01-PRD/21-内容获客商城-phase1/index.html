竞品对标 · 商家端是否做 H5？

知识付费 / 私域 SaaS：商家完整后台普遍为 PC Web；移动端用 APP / 小程序做轻量经营，而非 H5 版全功能后台。

竞品商家完整后台商家移动端说明
小鹅通 PC Web 商家版 APP 管理台不支持嵌入 SDK；「鹅零售」小程序做核销扫码
有赞 PC 商家后台 门店 / 微商城 APP H5 多指买家店铺渠道，非商家管理端
千聊 PC Web 讲师助手 APP 移动侧重开播与提醒，非全功能后台
知识星球 PC Web 星主 APP 审核与成员管理以 PC 为主
Phase 1：商家店后台仅做 Web（与竞品一致）。A21/A22 提供 Web + H5 线框（主站入口，非完整店后台）。
Phase 2 可选：店员核销做 H5 / 小程序（对标鹅零售，覆盖 shop_clerk）；完整后台仍 Web。
买家端 H5（公众号内嵌）可与小程序并行，与商家管理端无关。
