## 1. 数据与接口（无迁移）

### 1.1 保持不变的表

- `campaign_contents`（活动↔内容）  
- `agent_memory_facts`、`content_templates` / 顾问模板  
- `contents`（不加 `campaign_id` 列）

### 1.2 Schema / API 变更

| 位置 | 变更 |
|------|------|
| `AgentChatRequest` | `+ campaign_id`；可选 `platform` / `content_format` / `video_duration_sec` |
| `ContentGenerateRequest` / `ContentProposalsRequest` | `+ video_duration_sec` |
| `handle_chat` / `stream_chat` | 透传 `campaign_id` / 时长 → 生成；生成后 `revise_until_pass` |
| Workflow `input` | 透传 `campaign_id` → `_build_tool_args` → `_generate_content` |
| `run_generate_content` | `body.campaign_id` 时幂等 `link_content` |
| `POST /content/generate` | 若服务层已关联，去掉路由层二次插入或做成幂等 |

### 1.3 前端 API

| 位置 | 变更 |
|------|------|
| `apps/web/src/api/client.js` | 新增 `agentApi.chatStream(sessionId, body, { onEvent })`（`fetch` + `ReadableStream` / SSE 解析；带 Authorization） |
| `Create.vue` | Agent 路径改 stream；body 带 `campaign_id`；修白屏；文案；可选恢复会话状态（P1） |

## 5. 风险与注意

| 风险 | 缓解 |
|------|------|
| Create 同时维护 Workflow / Agent 双路径 | 以 `VITE_AGENT_WORKFLOW` 测两分支；统一关联点减少漏改 |
| SSE 与 axios 拦截器不兼容 | 独立 `fetch` + token；勿走默认 json interceptor |
| `link_content` 权限/404 | 非法 campaign → 400；权限不足与现网 CRM 一致 |
| 报告诱导加 scene UI | Code review 对照 FR-ADVISOR-23 / §3.22.5 |
| 误开迁移 063 | CI：本 PR diff 不得含 `alembic/versions/06*` 新文件（相对 v1.0 已合入集） |
