## 0. 公共前置与账号

| 代号 | 账号用途 | 准备方式 |
|------|----------|----------|
| `ADM` | 平台超管 | `13800000000` + 约定密码；`workspace=platform` |
| `OPS` | 平台运营（有 merchant 读写、无 initiate 若矩阵如此） | seed |
| `CS` | 商家管家（有 initiate，无 subscription.manage） | seed + 已分配 prospect |
| `MCH_NEW` | 未入驻商家 admin | seed：有 tenant，无 merchant，无 pending |
| `MCH_PENDING` | 审核中商家 | 已有 pending 申请 |
| `MCH_OK` | 已入驻 active | seed |
| `MCH_OTHER` | 另一租户商家 | 用于 IDOR |
| `CLERK` | 店员 | 仅核销三权 |

**环境**：

```text
API: http://127.0.0.1:8003   # 以实际为准
Web: http://127.0.0.1:5173
SMS_PROVIDER=mock
# 入驻本表不依赖支付
```

**通用 API 断言约定**：

- 业务失败：`422` 且 `detail` 为**中文**（可 toast）
- 无权限：`403`
- 冲突：`409`
- 成功写：`200`/`201`；列表含 `total`/`items` 或文档约定结构
