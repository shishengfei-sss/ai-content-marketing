## 1. P05 清结算

### 1.1 业务规则断言（先于 UI）

| ID | 规则 | 测法 | 期望 |
|----|------|------|------|
| TC-P05-R01 | T+7 未满不入池 | paid_at=昨天；跑日任务 | 不进开放账期 |
| TC-P05-R02 | T+7 已满入池 | paid_at=8 天前 | 入池 |
| TC-P05-R03 | 日跑 ≠ 出批 | 仅跑日任务 | **不**新增 pending 打款批（除非恰逢周关账） |
| TC-P05-R04 | 周关账 | 关账日触发 | 每 tenant+shop **1** 条批次 |
| TC-P05-R05 | net>0 → pending | 造正净额 | status=pending |
| TC-P05-R06 | net=0 → closed | | 可见；无打款按钮 |
| TC-P05-R07 | net&lt;0 → carried_forward | | 可见负应结；不自动追款 |
| TC-P05-R08 | 公式 | 核对 | period_net=gross-fee-refund_reversal；net=period_net+opening |
| TC-P05-R09 | 批次号 | | `JS`+ISO 周+4 位；不嵌商家号 |
| TC-P05-R10 | 禁止手工新建/改金额 | API 若有 | 404/403/422 |
| TC-P05-R11 | 清退后 | closed 商家 | 在途 pending 可结；之后 F10 跳过 |

### 1.2 列表与详情 UI

| ID | 步骤 | 期望 |
|----|------|------|
| TC-P05-L01～L07 | 筛选状态/商家/周期；排序批次号/成交额/时间 | 五件套 |
| TC-P05-F01 | 列：批次、商家、周期、成交额、抽成、**退款冲正**、应结、生成时间、状态 | 冲正=0 显示 — |
| TC-P05-F02 | 打开详情 | 明细只读；含 opening 若有 |
| TC-P05-P01 | CS 访问 | 403 / 无菜单 |
| TC-P05-P02 | FIN 可进 | 200 |

### 1.3 打款状态机（P05-B / C）

| ID | 前置 | 操作 | 期望 |
|----|------|------|------|
| TC-P05-B-V01 | pending 但收款账户无效 | 确认打款 | 422 |
| TC-P05-B-V02 | net≤0 批次 | 打款 | 无按钮或 422 |
| TC-P05-B-F01 | F_BATCH_PENDING 账户有效 | 确认打款 + 凭证 URL | status=paid；paid_at；settled_at 回写 |
| TC-P05-B-F02 | 含 opening&lt;0 吸收结转 | 打款成功同事务 | 源 carried_forward → offset_settled；offset_by_batch_id=本批 |
| TC-P05-B-E01 | 打款失败标 payment_failed | | **不**回滚已 offset_settled（若原子失败则整单回滚——二选一须与实现一致并测） |
| TC-P05-C-F01 | payment_failed 重试成功 | → paid | |
| TC-P05-C-F02 | 退回待结算 | → pending | |
| TC-P05-B-V03 | 凭证 URL 非法 | 422 | |
| TC-P05-B-V04 | 凭证空（若必填） | 422 | |
| TC-P05-F03 | offset_settled 详情 | 可链到吸收批次 | 只读 |

### 1.4 退款与入批衔接

| ID | 场景 | 期望 |
|----|------|------|
| TC-P05-REF-01 | 未入批前退款 | 不进本批 |
| TC-P05-REF-02 | 已入批未打款后退款 | **下一周期** refund_reversal 冲正 |
| TC-P05-REF-03 | 列表冲正列 | 显示金额 |
