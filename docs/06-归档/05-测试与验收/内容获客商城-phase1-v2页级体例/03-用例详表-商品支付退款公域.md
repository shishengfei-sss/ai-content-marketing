### 1.2 状态机（H1）

| ID | 操作 | 期望 |
|----|------|------|
| TC-A02-F01 | 保存草稿 | status=`draft` |
| TC-A02-F02 | 合法提审 | `pending_review`；返回 auto_result 摘要 |
| TC-A02-E01 | 直接 PATCH status=`on_sale` | **422** 禁止跳状态 |

## 2. M3 私域支付详表（H2）

### 2.1 主路径 TC-X-PAY-F01 / TC-M04-F01～F02

| 步骤 | 动作 | 断言 |
|------|------|------|
| 1 | F_BUYER 打开 F_SKU_COURSE 详情 | 价=服务端价 |
| 2 | 下单 `POST /mp/shop/orders` | 201；status 待付；`price_cents`/`title_snapshot` 快照 |
| 3 | 预支付 | 返回 mock pay params |
| 4 | Mock notify 成功 | order=`paid`；payment success |
| 5 | 查 entitlement | **恰好 1 条** `active`，关联 order_id |
| 6 | UI M05/M06 | 成功页；已购可见 |

### 2.2 价格与篡改

| ID | 操作 | 期望 |
|----|------|------|
| TC-M04-V01 | body 带 `price_cents=1` 而 SKU=9900 | 订单仍 9900 或 422 拒绝客户端价 |
| TC-X-PAY-V01 | F_SKU_DRAFT 下单 | 409/422 非 on_sale |
| TC-X-PAY-V02 | 下单成功后查 contacts 表 | **无**新增 Contact 行 |

### 2.3 幂等与异常（R4 重叠）

| ID | Mock 注入 | 期望 |
|----|-----------|------|
| TC-MOCK-WX-02 | 同一 transaction_id notify×10 | entitlement count=1；HTTP 仍成功 |
| TC-MOCK-WX-03 | bad_sign | 订单仍待付；无权益 |
| TC-MOCK-WX-04 | amount_mismatch | 拒；可观测日志/审计字段 |
| TC-M04-E01 | 用户取消支付 | 可重新支付；不产生权益 |
| TC-M04-P01 | 无 token | 401 |

### 2.4 并发（加分/P1）

| ID | 操作 | 期望 |
|----|------|------|
| TC-X-PAY-E02 | 两请求同时 notify 同单 | 仍 1 权益（唯一约束或行锁） |
