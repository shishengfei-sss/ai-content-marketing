# 用例详表 · 异常与对抗操作全集（强制）

| 字段 | 值 |
|------|-----|
| 文档版本 | **v1.0-qa-abnormal** |
| 配套 | [00-测试方案与用例全集.md](./00-测试方案与用例全集.md) |
| 原则 | **凡有正常路径，必须有对等异常路径**；只测 Happy Path = 本轮 **不通过** |
| 类型码 | `E` 异常 · `V` 校验 · `P` 权限/越权 · `X` 对抗/篡改 · `N` 网络/环境 |

> 本册是 **异常操作权威清单**。详表 02～06 中的 `*-E*`/`*-V*`/`*-P*` 与本册映射；执行时两处都要能勾到。  
> 自动化：`verify_shop_*` 与 UI 脚本必须包含本册「P0 异常」子集，否则 QC/QA 拒收。

## 0. 强制规则（写进每轮出口）

### 0.1 每个可操作功能的最低异常包

对任意「提交 / 支付 / 审核 / 开通 / 退款 / 核销 / 映射 / 打款」类操作，至少覆盖：

| # | 异常类 | 必测 | 期望通性 |
|---|--------|------|----------|
| 1 | **校验拒绝** | 缺必填、超长、非法格式、非法枚举 | 422 + 中文 `detail`；UI 红字/toast；**数据未脏写** |
| 2 | **权限拒绝** | 无权限角色、跨壳 token | 403；UI 无入口 |
| 3 | **状态拒绝** | 错误状态下点操作（如已通过再审、已退再退） | 409/422；状态不变 |
| 4 | **冲突/重复** | 连点、重放、并发双提交 | 只生效一次；无双单/双权益 |
| 5 | **资源不存在/越权 ID** | 改 URL 里别人的 id | 404/403；不泄露他租户数据 |
| 6 | **业务规则拒绝** | 暂停营业下单、未过审上架、部分退款等 | 按 PRD 文案拒绝 |

缺任一类且该功能存在对应风险 → **R1 出口 Fail**。

### 0.2 正常 : 异常 比例建议

| 层级 | 建议 |
|------|------|
| 主路径功能（支付/入驻/退款/审核） | 异常用例数 ≥ 正常用例数 |
| 普通 CRUD | 每字段矩阵（V）+ 至少 2 条 E/P |
| 只读列表 | 至少：越权、空态、非法筛选、超大 page |

### 0.3 异常结果判定（防假绿）

异常用例 **Pass** 必须同时满足：

1. 接口/页面按预期失败（对的状态码/文案）  
2. **副作用为零或符合文档**（未多开权益、未多扣次、未改错状态）  
3. 可再次用合法路径成功（系统未卡死）  
4. 日志无堆栈明文打给前端；无 PII/密钥泄露  

只看到 toast、没查库 → **记为未测完**。

## 2. 分域异常清单（与 02～06 对齐）

### 2.1 入驻 / 壳 / 权限 → 详表 02

| 正常对照 | 异常必测（本册 ID 或 02 已有） |
|----------|--------------------------------|
| 登录成功 | 错密、锁（若有）、跨 workspace 串权 P-02/P-08 |
| 注册成功 | 重号、非法手机、重名工作台 V01/V02 |
| P02-A / A20 提交 | 字段矩阵全套 V + pending 重复 409 + 已入驻 409 |
| P03 通过 | 无权限、重复审、驳回原因空、敏感 reveal 无权 |
| 暂停/清退 | 无确认 ack、重复清退、无权限、暂停下买家新购 |

### 2.2 商品 / 支付 / 退款 / 公域 → 详表 03

| 正常对照 | 异常必测 |
|----------|----------|
| 保存草稿/提审 | 缺字段、机审拒、直接 on_sale、无审核权 |
| 下单支付 | 改价、非 on_sale、未登录、取消支付、坏签、错金额、重放 |
| 退款 | 部分退、重复退、无权、已开票红冲标记 |
| 核销预约 | 双核、过期码、冲突档、扣尽 |
| 公域 | 未过闸、未开通组合、重放、过期领权、错 token |

### 2.3 套餐 → 详表 04

| 正常对照 | 异常必测 |
|----------|----------|
| 建字典/模板 | 重名、非法 code、0 功能上架、改只读字段 |
| P11 开通 | 管家开通 403、closed/suspended、未上架模板、主体类型不符、日期颠倒 |
| 换档/加购 | 选错类型、到期态禁加购、无主套餐加购 |
| 续费结案 | 取消原因 &lt;4 字、无权限取消 |

### 2.4 结算 / 短信 / 进件 → 详表 05

| 正常对照 | 异常必测 |
|----------|----------|
| 确认打款 | 账户无效、net≤0、非法凭证、无权限、禁止改金额 |
| 短信 | 密钥空、未审模板分配、发送失败可查 |
| 进件 | 缺材料、未开通测支付、重复提交、店员进入 |

### 2.5 买家 → 详表 06

| 正常对照 | 异常必测 |
|----------|----------|
| 浏览购买 | 暂停店、下架品、改价、连点下单、支付失败 |
| 学课履约 | 无权益、revoked、锁课时、坏媒体 |
| 退款开票 | 部分退、不可退态、开票字段非法、重复开票 |
| 领权 | 过期、错码、二次领取 |

## 3. 异常操作 UI 体验要求（一并判）

异常不只「接口对」，界面也要过：

| ID | 检查 |
|----|------|
| TC-ABN-UI-01 | 错误文案为中文、可理解；禁止只显示 HTTP 500 |
| TC-ABN-UI-02 | 校验错误定位到字段；不整页红无焦点 |
| TC-ABN-UI-03 | 失败后按钮恢复可点（除非业务锁定） |
| TC-ABN-UI-04 | 权限无入口优先于点了才 403（点了也必须 403） |
| TC-ABN-UI-05 | 危险操作失败不关闭确认框丢上下文（或明确重置） |
| TC-ABN-UI-06 | 网络失败有重试，不白屏 |

## 4. P0 异常最小集（每轮 R1 必跑 · 自动化优先）

交付/批次出口前，下列 **必须自动化或等效手工带库断言**：

1. TC-ABN-P-02 商家调平台  
2. TC-ABN-X-01 跨商家订单 IDOR  
3. TC-ABN-ST-03 跳状态上架  
4. TC-ABN-ID-01 支付重放  
5. TC-ABN-ATK-01 改价  
6. TC-ABN-ATK-06 部分退款  
7. TC-ABN-N-01 坏签  
8. TC-ABN-N-06 挂载闸拒单  
9. TC-ABN-ST-01 重复入驻  
10. TC-ABN-ATK-05 revoked 再学  

**10 条全过** 才允许该批次进入「可演示」候选；与开箱标准中的资金/权限类一致。
