## 0. 账号 / 店铺 / 商品工厂

| 代号 | 含义 | 准备 |
|------|------|------|
| `SHOP_OK` | 营业中店；课/资料/服务各 ≥1 个 `on_sale` | seed |
| `SHOP_PAUSE` | 店铺 paused 或商家 suspended | seed |
| `SKU_COURSE` / `SKU_DIGITAL` / `SKU_SERVICE` | 三类在售 | seed |
| `SKU_OFF` | `off_sale`（列表默认不展示） | seed |
| `SKU_FREE` | 价格=0 的在售品（若有） | seed |
| `BUYER_NEW` | 无购买记录；可登录 | seed |
| `BUYER_OWN` | 有 active 课程权益 | seed |
| `BUYER_MULTI` | 同 tenant 两店均有已购 | seed |
| `CLAIM_OK` / `CLAIM_EXP` | 领权 token 有效/过期 | seed |
| `ORDER_PAY` | 待支付订单 | 下单未付 |
| `ORDER_PAID` | 已支付可退款订单 | seed |

**通用约定**：

- 业务失败：中文 toast/页内文案；**禁止**整页白屏或裸 500
- 金额展示：元，两位小数；与服务端 `price_cents/100` 一致
- 未登录访问需登录页：→ **M01**，带 `redirect`，登录后回跳
