## 0. 账号与数据工厂

| 代号 | 用途 |
|------|------|
| `ADM` / `OPS_PLAN` | 有 `plan.manage` |
| `OPS_SUB` | 有 `subscription.manage` |
| `CS` | 管家：可 P02-B-R，**无** subscription.manage |
| `MCH_FREE` | 已入驻、无付费主套餐（或已到期） |
| `MCH_BASIC` | 已入驻 + active basic |
| `MCH_CLOSED` | 已清退 |

**工厂**：

| ID | 产出 |
|----|------|
| `F_DICT` | 至少 1 分组 + 3 叶子：`bool` 开关、`int` 配额(max)、`usage` 次数(sum) |
| `F_PLAN_MAIN` | 未上架主套餐草稿 |
| `F_PLAN_PUB` | 已上架 `basic` / `flagship`（replace_group=main） |
| `F_ADDON_PUB` | 已上架加购包 stackable=true |
