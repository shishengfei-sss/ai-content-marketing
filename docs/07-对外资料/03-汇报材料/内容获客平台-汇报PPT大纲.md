## 交易合规四道闸（第 13 页 · 与 PRD 对齐）

| 闸 | 要点 |
|----|------|
| 主体资质闸 | 个人 / 个体工商户 / 企业；执照或身份证 · 支付进件 |
| 商品上架闸 | 机审 + 平台人审；未过审不可私域上架 |
| 公域与稽查 | 过上架闸才可挂抖店/课程库；举报抽检 · 强制下架 |
| 底栏并列 | 商家多店 · SaaS 套餐（P10 可配）· 与素材闸分工 |

---

## 素材合规（第 12 页）

- **选源闸**：商用授权白名单（图/视/音）；AI 走商用套餐
- **成片闸**：license 元数据可追溯；未授权不可导出
- **发布闸**：文案合规 + 素材合规 + 人审

---

## Phase 1 边界（第 14 页 · 与 PRD 一致）

**做**：三类主体入驻 · 多店铺 · P10/P11（验收期人工开通）· 虚拟/服务三件套 · 支付权益 · 小程序履约 · 商品合规 · 抖音 Mx  

**后移 P2+**：套餐自助购与剩余天数折算 · 店铺装修 · H5 完整商城 · 实物/门店等

**硬验收**：入驻 → 商品合规 → 私域可售 → 公域挂载 → 履约 → 退款关权益
