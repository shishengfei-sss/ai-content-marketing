## 0. 一页结论

**现在对外能卖的，只有已上线的「智营获客」：AI 写获客内容 + 内置 CRM 跟进成交。**  
内容获客商城仍在 Phase 1 开发，未达开箱标准，**不能当商品卖、不能招商、不能承诺四平台成交。**  
公域「卖课」与现有执照、抖音教培定向邀约都不匹配，**试跑阶段明确不做。**

## 0.1 经营范围加不了培训时怎么卖

执照已有信息技术咨询、企业管理咨询、软件开发，**没有教育培训也不打算加上**时：不是「换个名字继续卖课」，而是 **永久不走教培 SKU**。判定口诀（试跑说明原文）：**一对多 + 系统教学 = 课（不能卖）；一对一 + 非标交付 = 咨询（能卖）。**

平台看实质不看话术。录播、训练营、专栏、小黄车「AI 培训」写成「咨询」仍是课。用资料包、私信加微信绕过教培，试跑说明 §10 **明确不做**。

### 能卖的三样（现执照覆盖）

| 卖什么 | 合同 / 商品怎么写 | 怎么交 | 钱怎么收 | 现在能不能做 |
|--------|-------------------|--------|----------|----------------|
| **智营获客（软件）** | 软件使用 / 技术服务，不要写「培训系统」「网课平台」 | 开通租户，用创作 + CRM | 对公合同；系统内无收银台 | **G0 就能卖**（已交付） |
| **一对一咨询 / 诊断 / 陪跑** | 信息化咨询、企业管理咨询、AI 落地诊断；标题禁课/培训 | 约一次远程或出一页书面结论 | 对公；抖店只上咨询类测试/正式服务品 | **G0 就能卖** |
| **对公企业内训 / 工作坊** | 技术服务或咨询合同，**不走店铺教培类目、不挂小黄车** | 上门或线上会议，不对公域上架录播 | 只对公 | **能签合同**；不能当成店里的课卖 |

财务方向只卖「制度梳理 / 票据信息咨询 / 预算绩效评价」这类咨询，**不卖会计考证班，也不做代账报税**（缺代理记账许可）。

### 商品与内容怎么命名

可以：企业信息化咨询、远程答疑、诊断、陪跑、SaaS 订阅、对公内训（合同用语）。  
不可以：课、课程、网课、培训、教程、训练营、知识付费、专栏、听课、课件、试听（试跑说明 §5.3）。

公域（抖店）类目只选咨询 / 信息技术 / 软件。主图不要教室、黑板、讲师。履约写成「下单后联系、约一次、给结论」，不要写成「课时 / 更新 / 班级群」。

### 三条成交路径（按成熟度）

1. **现在：对人卖软件。** 存量转介绍，演示「创作 → 线索 → 报价」，对公开通智营获客租户。这是加不了培训时的主业。  
2. **现在：对人卖咨询。** 同一批客群（财务咨询公司、信息化、对公服务）可叠加「诊断 / 陪跑」；抖店只作为咨询探针，不挂课。  
3. **商城开箱后：私域卖服务卡。** 咨询预约、次数卡；资料包只能是交付物（方案、纪要），**不能当录播课容器**。仍不招商「卖课商家」。

### 加不了培训就永久放弃的

- 公域上架 AI / 创业 / 管理 / 财务培训课  
- 用智营获客当「卖课平台」去招教培商家  
- 启用 `02-内容获客运营` 卖课 Deck 对外招商  
- 分销别人已报白的课当主业（试跑说明列为更轻路径，但本计划 **不做服务商 / 不代运营**，不作为推荐卖法）

G2「经营范围含培训才招教培商家」在此前提下 **取消**。G2 只保留：软著后的抖店订单回流、微信进件后的真收款。

## 2. 现在能对外说的价值主张

**一句话（对齐整合 PRD，不新编定位）：**  
智营获客 = 通用 AI 营销内容创作顾问 + 内置 SaaS CRM，打通「能写出获客内容 → 能把线索跟到回款」。

**对标口径（方案摘要原文）：** 竞品卖「店」与履约；我们卖 **生产 + 成交 + 运营**。  
现阶段对外只兑现「生产 + CRM 成交运营」；「店与履约」等商城开箱后再讲。

### 2.1 15 分钟演示剧本（只走已交付页）

环境：现网 `192.168.20.200` 或本地 Web `5173`；用约定测试/演示租户，不要用平台管理员号给客户看后台。

1. 登录 → 选公司。  
2. 营销顾问：按客户真实题材生成一条小红书笔记或抖音脚本（方案不扣额度，正文扣 1）。  
3. 指出合规自检结果；说明发布是导出/Mock，**不是**官方一键发到抖音。  
4. 把内容关联到一条营销活动。  
5. 新建线索 → 跟进 → 转化为客户/商机。  
6. 若客户是 B2B：走报价（含价税）或轻量 CPQ → 说明可转合同/订单。  
7. 打开工作台/报表：回款或合同到期提醒（v1.2 已有）。

演示结束只承诺刚才点过的能力。招标池、H5、商城入口若未准备好，本场不要点。

### 2.2 明确不能承诺

| 客户若问 | 标准回答 |
|----------|----------|
| 能自动发抖音/小红书吗 | 不能。可以生成并导出，官方自动发布未做。 |
| 能在你们店里卖课、挂四平台吗 | 商城还在做；公域卖课现执照也不允许。 |
| 有没有现成的卖课商家后台 | 没有对外开放。 |
| AI 销售经理能替我分线索、发报价吗 | 方案和演示稿有，**产品尚未按执行计划交付**。 |
| 微信里直接付钱吗 | 主产品无收银台；商城真支付还要进件。 |
| 我们自己开个教培店你们代运营 | 试跑口径：**不代运营、不做服务商**。 |

## 3. 客群：只找现在接得住的

不按「知识付费风口」去找商家。按 **已交付产品 × 现有执照 × 原用户画像** 交集。

### 3.1 现在就找（G0）

| 优先 | 为什么接得住 | 不要讲成 |
|------|----------------|----------|
| 小财务 / 咨询公司的市场或销售负责人 | SRS 原画像；创作顾问 + CRM 跟进就是他们的日常 | 不要讲「代账/报税班」（执照没有代理记账许可） |
| 信息化 / IT 咨询、企业管理咨询、对公内训团队 | 执照类目对得上；内容获客 + 线索跟进可落地 | 不要讲「培训课 / 训练营」上公域 |
| 已有销售漏斗、需要报价/合同的 B2B 小团队 | v0.7～v1.5 交易域已交付 | 不要讲「AI 销售经理已上线」 |

**找人方式（与环境匹配）：** 股东/同事转介绍、已有业务关系、现场演示。  
**不找：** 需要公域卖课的知识付费达人、要挂小黄车的教培机构、要实物电商的零售商、要代运营的商家。这些人当前产品接不住，谈了也交不了货。

### 3.2 商城开箱后才找（G1）

私域试点商家：愿意用 H5/小程序卖 **咨询预约、次数卡、资料包**（虚拟/服务），接受平台 **人工开通套餐**，接受支付先 Mock 或等进件后再真收。  
人数：**1～2 家**，不要招商会。

### 3.3 不再等待的教培线

经营范围加不了培训时，**不把教培/知识付费商家当目标客群**。卖课 Deck 继续只作内部研究。G2 只做真推送 / 真收款，不招商教培。

## 4. 三阶段推广（对齐已有计划，不另起版本号）

研发批次仍用 M0–M8；商务线仍用 B-M1 / B-M3 / Mx。下面 **G0/G1/G2 只是推广阶段**，避免和研发 M 混淆。

### G0 · 即日起（不依赖商城开箱）

目标：证明「智营获客有人愿意用」；同时按试跑说明把平台自己的公域探针跑通。

**商务 / 销售**

1. 列出 5～10 个可约的存量关系（财务咨询、信息化、对公内训），不冷启投放。  
2. 约 3 场一对一演示，只走 §2.1 剧本。  
3. 试点合作用线下协议：开通租户 + 平台 AI 额度（默认 100 次）或客户自备 Key；**系统内不收款**。  
4. 按 [试跑说明 §9.1](../../02-执行计划/支付抖音启动计划/平台自营公域试跑说明.md)：开抖店企业店（咨询/软件类目，0 元试运营）→ 上测试商品「企业信息化咨询 · 15分钟远程答疑（测试）」内部买一单并真实履约 → 同步登记软著。有余力再开微信小店（不要选教培）。快手、小红书先不开。

**产品 / 研发（不阻塞推广，但阻塞「商城可对外」）**

- 继续商城 Phase 1，直到开箱标准签收。  
- 系统内：平台公司 = 商家 001，Mock 走通入驻→上架→付→上课→退款（试跑说明 §9.2）。  
- 不要把「Phase 1 完成」定义成抖音真卖课首单。

**内容（用自己的产品）**

- 用营销顾问产出咨询/信息化向内容（笔记、脚本），合规自检过后再用。  
- 标题和详情 **禁止**出现：课、课程、网课、培训、教程、训练营、知识付费（试跑说明 §5.3）。  
- 不挂橱窗、不投流、不直播推测试商品。

### G1 · 商城开箱签收之后

前置：开箱标准 H1～H6、Q1～Q3、D1～D7 全过；演示剧本可独立跟做。

1. 对内：按开箱标准 15～30 分钟走「入驻→上架→付钱→履约→退款→Mock 公域」。  
2. 对外：邀请 **1～2 家** G0 里已经在用智营获客、且品类是咨询/服务的客户，人工开通 basic。  
3. 商品只允许虚拟/服务（咨询预约、次数卡、资料包）。**不上「课」**。  
4. 真收款：等商务 B-M3 微信进件；进件前只 Mock 或对公线下。  
5. 公域订单：无软著前继续 Mock；软著下来再改真抖店推送（试跑说明 §9.3）。视频号小店若已开，再评估接回调（代码目前未接，要单独立项）。

### G2 · 资质与通道齐了之后

| 条件 | 才允许的推广动作 |
|------|------------------|
| 软著已下 + 自用型应用过审 | 对外说「抖店订单能进我们系统」 |
| 微信进件真机过 | 对外说「小程序/H5 能真收款」 |

G2 之前，全域四平台 PPT 只给内部/投资人讲路线，**不作为销售话术附件发给商家。**
