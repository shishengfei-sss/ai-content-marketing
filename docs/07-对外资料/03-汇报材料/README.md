# 汇报材料

面向**决策层 / 对外汇报**的成套材料，**不限于 PPT**。允许格式：

| 格式 | 典型用途 | 本目录示例 |
|------|----------|------------|
| `.pptx` | 决策层路演、方案汇报 | 内容获客全域四平台、四域智能体 |
| `.html` | 交互式 pitch、浏览器演示稿 | `AI销售经理演示稿/AI销售经理演示稿.html` |
| `.pdf` | 定稿分发、打印 | （可按需导出后放入本目录） |
| `.md` | 汇报提纲、章节索引、推广计划（非 PRD 规格） | `内容获客平台-汇报PPT大纲.md` · `智营获客-商业推广计划.md` |

文字版方案摘要见 [00-总览/内容获客平台方案摘要.md](../../00-总览/内容获客平台方案摘要.md)。
