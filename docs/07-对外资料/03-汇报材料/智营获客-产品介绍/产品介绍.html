智营获客

AI 写出获客内容，CRM 跟到回款

面向市场、销售与企业负责人 · 以已上线能力为准

适合谁

中小企业里要同时管「发什么内容」和「线索有没有跟」的人：

  • 咨询、信息化、对公服务公司的市场或销售负责人
  • 需要报价、合同、回款，而不是只做线索登记的销售团队
  • 一人兼顾多块业务、需要按公司切换工作空间的管理者

一个人可以用同一个手机号加入多家公司。登录后选择当前公司，数据和权限跟着公司走。

解决什么问题

常见情况是两套工具各干各的：内容在文档里生成，线索在表格里跟，报价在另一套软件里做。中间靠复制粘贴，活动效果对不上成交。

智营获客把这条链放在同一个系统里：

写内容→ 营销活动→ 线索 / 客户→ 商机→ 报价→ 合同 / 订单→ 回款

能做什么

1. AI 营销创作顾问

用自然语言说明题材、平台和要点。系统先给出方案（不占用平台次数），确认后再生成正文（成功计 1 次）。

  • 公众号文章、小红书笔记、短视频脚本等常见获客形态
  • 可注入企业知识库与品牌语气
  • 实时生成；对敏感词和夸大承诺做合规检查，可按提示改稿
  • 历史会话保留；写好的内容可挂到营销活动
发布方式：公众号可在配置服务号后发布（需完成备案）；小红书、抖音目前是导出文案，由人工发布。系统不会在未确认时自动发出去。

平台提供默认 AI 次数（每家公司默认 100 次，仅正文成功计次）；也可以填写自有模型密钥。

2. 线索、客户、商机

  • 线索：新建、导入表格、跟进、任务、转化为客户；转化时去重，可同时建商机
  • 客户 360 视图、标签、来源渠道
  • 商机管道看板；产品明细可生成报价
  • 按「本人 / 团队 / 全公司」看数据，由权限强制

3. 报价、合同、订单、回款

  • 报价可转合同或订单，行上支持价税
  • 需要按参数计价时，可用轻量配置报价（写入同一套报价单）；低于毛利红线会提示确认
  • 合同模板；一笔合同可拆多笔订单
  • 工作台提醒回款到期、合同到期；交易报表看回款率、账龄、阶段停留

若你们跟招标：平台维护公共招标信息，按贵司客户画像匹配后，销售认领进自己的线索再跟进。认领不会直接变成商机。该能力在电脑端。

4. 电脑端与手机端

电脑浏览器为完整功能。手机浏览器可完成登录、创作、线索、客户、任务、商机等主流程。招标匹配与配置报价目前在电脑端。

一次演示通常怎么走

  1. 登录并进入一家公司
  2. 按一个真实选题写出笔记或脚本，看方案、正文和合规提示
  3. 把内容挂到一场营销活动
  4. 新建线索 → 跟进 → 转为客户或商机
  5. 如需报价：从商机生成报价，看价税合计
  6. 打开工作台，看到期提醒

当场只承诺刚才实际点过的功能。

当前边界

您可能关心当前做法
能不能一键发到抖音、小红书不能代发。可以生成并导出，由人工发布
能不能在系统里向客户收款按企业使用开通，没有面向买家的收银台
能不能开店卖课、挂多个短视频平台成交不是当前交付范围
数据谁能看见按公司隔离；公司内再按角色和本人/团队范围

下一步

适合先做一场对着真数据的演示，再开通试用公司账号。试用期间可用平台 AI 次数，或配置贵司自己的模型密钥。
