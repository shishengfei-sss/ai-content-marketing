# 智营获客 · 产品介绍视频脚本

仓库**不附带 MP4**。按本脚本用本机录屏即可出片。画面来源只有两种：本目录 [演示稿.html](./演示稿.html)，或已上线的智营获客界面。

配套口播事实与 [产品介绍.md](./产品介绍.md)、[商业推广计划](../智营获客-商业推广计划.md) §2 / §6 一致。禁止把未交付功能拍进去。

---

## 0. 拍之前

| 项 | 要求 |
|----|------|
| 工具 | Windows 游戏栏 `Win + G`，或 OBS。导出 1920×1080、H.264、30fps |
| 环境 | 演示稿用 Chrome 全屏；真机用生产或本地 Web，**不要**用平台管理员号 |
| 账号 | 普通企业管理员或销售经理；公司名称用真实试点名或中性名，不要「测试租户 001」 |
| 隐藏 | 书签栏、下载条、验证码 Mock、内网 IP 可保留但不念出 |
| 不要入镜 | 商城 / 内容获客菜单、AI 销售经理、卖课、测试手机号大特写 |
| 口播禁词 | 一键发抖音、四平台成交、开店、卖课、保证获客、已上线销售经理 |

字幕：后期按口播全文加；没有公网下单页，片尾不要二维码小店，只留对接人姓名或企业微信。

建议成片顺序：**先拍 V1（当天能发出去）→ 再拍 V3（会后发给看过演示的人）→ V2 可用 V1 加长或从 V3 剪。**

## V1 · 60 秒（转发 / 会前）

**画面：** 只录 [演示稿.html](./演示稿.html)。打开后按 `F` 全屏，按 `T` 打开底部提词，按 `→` 翻页。每页停留约 7～8 秒。

**口播（可直接念，约 160 字）：**

> 智营获客，给中小企业市场和销售团队用。  
> 用 AI 写出获客内容，用同一套系统把线索跟到回款。  
> 很多团队是内容在文档里写，线索在表格里跟，报价在第三个软件里做，活动效果对不上成交。  
> 在智营获客里：先让顾问按题材出方案、再生成正文，有合规检查；写好的稿可以挂到营销活动。  
> 销售把线索跟成客户和商机，报价能转合同和订单，工作台会提醒回款到期。  
> 小红书和抖音目前是导出后人工发布，系统不会擅自发出去。  
> 建议先对着你们自己的选题走一遍演示。

**分镜**

| 秒 | 演示稿页 | 口播对应 |
|----|----------|----------|
| 0–7 | 封面「智营获客」 | 第 1～2 句 |
| 7–15 | 问题三卡 | 第 3 句 |
| 15–28 | 一条链 | 第 4 句前半（链） |
| 28–42 | 创作顾问 | 方案、正文、合规、活动 |
| 42–52 | CRM 四卡 | 线索到回款 |
| 52–60 | 边界或下一步 | 导出人工发；约演示 |

片尾定格封面 2 秒，左下角可加「产品介绍 · 非宣传片」。不要配保证成交的花字。

## V2 · 约 3 分钟（会前预热）

**画面：** 仍以演示稿为主（8 页都走完）。若已有 V3，可在「创作顾问」「CRM」两页各切 8～10 秒真机画面（创作对话框流出、商机看板），不要切商城。

**口播：**

> （0:00）智营获客。定位很简单：AI 写出获客内容，CRM 跟到回款。  
> （0:18）适合咨询、信息化、对公服务这类公司——市场要发内容，销售要跟单、要报价，往往是同一拨人。一个人也可以进多家公司，数据和权限跟着公司走。  
> （0:42）问题通常是工具是散的。稿件在聊天里，线索在表格里，合同在邮箱里，老板问这场活动带来几单，对不上。  
> （1:05）我们把一条链放在同一个系统里：写内容，挂到营销活动，跟线索和客户，推进商机，出报价、合同、订单，收到回款。  
> （1:28）创作这边：你用自然语言说题材和平台，系统先给方案、不计次数；你确认后再写正文。支持公众号、小红书笔记、短视频脚本。可以带上公司知识库和品牌说法。有敏感词和夸大承诺的检查。历史对话会留着。  
> （1:58）发布要说清楚：公众号在完成备案、配好服务号之后可以发；小红书和抖音目前是导出，由你们自己发。没有点确认，系统不会自动发。  
> （2:18）销售这边：线索能手工建、也能表格导入，跟进之后转客户、转商机，转化会做去重。商机看板可以拖阶段，明细能生成报价，报价能转合同或订单。工作台会提醒回款和合同到期。电脑是完整功能，手机浏览器能走主流程。  
> （2:48）当前没有向买家收款的收银台，也不做开店卖课。要了解是否适合，对着你们自己的一个真实选题走 15 分钟即可。

翻页节奏：封面 15 秒 → 适用 20 秒 → 问题 20 秒 → 一条链 20 秒 → 创作 35 秒 → 经营 30 秒 → 边界 20 秒 → 下一步 10 秒。

## V3 · 约 12 分钟真机（会后可发，一对一主片）

**画面：** 智营获客 Web。提前用贵司或试点公司的真实选题准备知识库（公司简介、服务说明即可）。创作题材禁止出现「课 / 培训 / 训练营」。

**准备点击路径（与推广计划演示剧本一致）：**

登录 → 选公司 → 工作台扫一眼 → 创作 → 生成方案与正文 → 关联营销活动 → 线索列表新建 → 跟进 → 转化 → 商机看板 → 生成报价（看价税）→ 工作台到期提醒。

**口播 + 操作（按段录，后期拼接；某步失败就停，不要即兴承诺。）**

### 0:00–0:40 开场（可叠演示稿封面 5 秒再切真机）

> 这是智营获客的实际界面。接下来用一个真实选题，走一遍从写内容到报价。只演示系统里已经有的功能。

画面：登录后的工作台。不要念 IP、不要念测试账号。

### 0:40–4:00 创作

> 进入创作。左侧是历史会话，可以接着上次写。  
> 我输入：给咱们「企业信息化咨询」写一条小红书笔记，面向制造业老板，强调先诊断再落地，不要承诺接单月入。  
> 系统会先出方案，这一步不占次数。方案可以改。确认后再生成正文，成功计一次。  
> 生成是一段一段出来的。如果有合规提醒，按提示改，不要强行过。  
> 这篇可以挂到营销活动上，后面看这场活动产出了哪些稿。  
> 小红书目前是导出后你们自己发，不是系统代发。

操作：等方案出现再点确认；正文出来后打开合规结果；点关联活动。若 LLM 超时，改口：「网络波动时可以重试；方案已经留在会话里。」不要改口成「一键发布」。

### 4:00–7:30 线索到商机

> 转到线索。可以筛选、也可以从表格导入。今天手工建一条。  
> 填公司名、联系人、手机，选销售地区。保存之后写一条跟进，比如「已发笔记、待约诊断」。  
> 转化为客户时，系统会处理同名去重，需要的话同时建商机。  
> 商机在管道上看，阶段可以拖。打开详情能看到跟进和产品明细。

操作：字段按界面必填来，不要空提交再解释「系统不好用」。转化后切到商机看板停 3 秒。

### 7:30–10:30 报价与工作台

> 从商机明细生成报价。行上有价税，合计能对上。  
> 如果产品按参数计价，可以用配置报价，结果还是写进这张报价单，不是另一套软件。低于毛利会提示，需要人点确认。  
> 报价之后可以转合同或订单。今天看到报价为止。  
> 回到工作台：回款到期、合同到期会在这里。报表可以看回款率和阶段停留。

若演示租户没有产品数据：提前建一个「信息化咨询 · 诊断」产品；不要现场空转「功能没有」。

### 10:30–12:00 收束

> 电脑端是全的；手机浏览器也能做创作和跟进。招标信息匹配和配置报价在电脑上。  
> 没有演示的：不会代发到抖音；没有买家在线付款；不是开店卖课。  
> 试用可以开一家公司账号，用平台次数或你们自己的模型密钥。操作细节在《用户操作手册》里。

定格工作台 3 秒结束。

## 拍坏了怎么剪

| 情况 | 处理 |
|------|------|
| 创作等待超过 8 秒 | 中间剪掉，留开头输入和正文出现 |
| 误点商城或平台后台 | 整段作废，不要用遮挡 |
| 口误说了「卖课 / 一键发」 | 重录该段；不要靠字幕改意思 |
| 弹出验证码 1111 | 剪掉特写 |

V1 当天就能用于转发。V3 建议在第一场真实演示成功后再拍，用客户同意的脱敏数据，不要用全是「张三测试」的列表。
