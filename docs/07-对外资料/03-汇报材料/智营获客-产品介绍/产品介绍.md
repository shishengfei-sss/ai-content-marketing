# 智营获客

**AI 写出获客内容，CRM 跟到回款。**

一份给市场、销售和企业负责人看的产品介绍。功能以当前已上线能力为准。

---

## 适合谁

中小企业里要同时管「发什么内容」和「线索有没有跟」的人：

- 咨询、信息化、对公服务公司的市场或销售负责人
- 需要报价、合同、回款，而不是只做线索登记的销售团队
- 一人兼顾多块业务、需要按公司切换工作空间的管理者

一个人可以用同一个手机号加入多家公司，登录后选择当前公司，数据和权限跟着公司走。

---

## 解决什么问题

常见情况是两套工具各干各的：内容在文档或聊天里生成，线索在表格里跟，报价在另一套软件里做。中间靠复制粘贴，活动效果对不上成交。

智营获客把这条链放在同一个系统里：

**写内容 → 挂到营销活动 → 线索与客户跟进 → 商机 → 报价 → 合同 → 订单 → 回款**

市场写的稿可以关联到活动；销售跟进的线索可以转成客户和商机；报价可以转成合同或订单；工作台会提醒回款和合同到期。

---

## 能做什么

### 1. AI 营销创作顾问

用自然语言说明题材、平台和要点。系统先给出方案（不占用平台次数），确认后再生成正文（成功计 1 次）。

- 公众号文章、小红书笔记、抖音脚本等常见获客形态
- 可注入企业知识库与品牌语气，避免每次从零描述公司
- 生成过程实时流出；对敏感词和夸大承诺做合规检查，可按提示改稿
- 历史会话保留，关掉再打开还能接着写
- 写好的内容可以关联到营销活动，方便看这场活动产出了哪些稿

**发布方式：** 公众号可在配置服务号后发布（需完成备案）；小红书、抖音目前是导出文案，由人工发布。系统不会在未确认时自动发出去。

平台提供默认 AI 次数（每家公司默认 100 次，仅正文成功计次）；也可以在设置里填写自有模型密钥，改走自己的额度。

### 2. 线索、客户、商机

- 线索：新建、导入表格、跟进、任务、转化为客户；转化时去重合并，可同时建商机
- 客户：360 视图（联系人、跟进、商机、订单）、标签、来源渠道
- 商机：管道看板拖拽阶段、跟进与附件、产品明细可生成报价
- 销售按「本人 / 下属团队 / 全公司」看数据，由权限强制，改不了界面也看不到别人的单
- 公海、评分、分配规则可配；右上角通知待办和到期事项

### 3. 报价、合同、订单、回款

- 报价可一键转合同或订单；报价行支持价税
- 需要按参数计价时，可用轻量配置报价（结果写入同一套报价单，不是另一套系统）；低于毛利红线会提示确认
- 合同支持模板；一份合同可以拆出多笔订单
- 订单可从商机、报价或合同生成；支持按金额规则审批、发货、发票、退款记录
- 回款分计划 / 实际 / 确认；工作台提示回款到期和合同到期
- 交易报表：回款率、账龄、负责人业绩、商机阶段停留

招标采购信息：平台维护公共招标池，按贵司客户画像匹配后，销售认领进自己的线索再跟进。认领不会直接变成商机。该能力在电脑端。

### 4. 电脑端与手机端

电脑浏览器为完整功能。手机浏览器可完成登录、创作、线索、客户、任务、商机等主流程。招标匹配与配置报价目前在电脑端。

---

## 一次演示通常怎么走

约 15 分钟，用贵司真实题材：

1. 登录并进入一家公司
2. 让顾问按一个真实选题写出小红书笔记或短视频脚本，看方案、正文和合规提示
3. 把这篇内容挂到一场营销活动
4. 新建一条线索，写跟进，转化为客户或商机
5. 如需报价：从商机生成报价，看价税合计
6. 打开工作台，看回款或合同到期提醒

当场只承诺刚才实际点过的功能。

## 当前边界（避免预期错位）

| 您可能关心 | 当前做法 |
|------------|----------|
| 能不能一键发到抖音、小红书 | 不能代发。可以生成并导出，由人工发布 |
| 能不能在系统里向客户收款 | 本产品按企业使用开通，没有面向买家的收银台 |
| 能不能开店卖课、挂多个短视频平台成交 | 不是当前交付范围 |
| 数据谁能看见 | 按公司隔离；公司内再按角色和本人/团队范围 |

## 下一步

适合先做一场对着真数据的演示，再开通试用公司账号。试用期间可用平台 AI 次数，或配置贵司自己的模型密钥。

操作细节见配套《用户操作手册》。商务联系由对接人当面约定。
