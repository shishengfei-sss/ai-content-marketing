# 产品版本交付线梳理

> **当前基线**：Alembic head 以仓库 `alembic heads` 为准（**v1.6 = `090`**）  
> **产品形态**：通用 AI 营销创作 + 内置 SaaS CRM

**主链路**：AI 创作 → 活动关联 → 线索/客户 → 商机 → 报价/合同 → 订单 → 回款/发票，外加运营报表与提醒。  
**v1.3 增补**：平台公共招标池 L1（手工/Excel/附件 AI）→ 租户 ICP 匹配 L2 → 纳入 CRM 线索 → 跟进后转商机；轻量 CPQ → **写入现有报价 `quotes`**。**无爬虫。**  
**v1.4**：产品规格型号基础数据 + 自定义字段接通 + 产品批量导入。  
**v1.5**：产品默认税率 / 标价含税语义 + 报价行价税 + 转订单透传（对齐订单 v1.0 公式）。  
**v1.6**：营销活动字段增强（预算/负责人/地区/细分露出 + 类型/预期线索/地点）。

**内容获客平台线**（与主版本线并行）：**AI 内容工厂 + 交易闭环 + CRM** 三位一体。Phase 0（创作顾问）✅；Phase 1 商城 MVP 📋 立项；Phase 2～5 智能体增强候选 v1.7～v2.0+。详见 [内容获客平台方案摘要.md](内容获客平台方案摘要.md) · [执行计划](../02-执行计划/内容获客平台-执行计划.md)。

## 三、未完成 / 明确延后

### 3.1 下一版候选（≥v1.7，尚未立项落地）

**主产品：**

- **财务售后闭环**：退货、发票红冲、客户对账单、坏账
- **价税 P2**：税码字典、出口 VAT、价目行税、尾差强制对齐

**内容获客平台线**（见 [方案摘要](内容获客平台方案摘要.md) §3）：

- **v1.7**：智能体 × 商城打通（创作关联商品、一键生成上架素材）
- **AI 底座（规划）**：资料分类 / 开箱六项 / 演示包 / 空库降级，与商城验收并行；详见 [22-内容获客AI能力规划](../01-PRD/22-内容获客AI能力规划/内容获客-AI能力规划.html)
- **v1.8**：商用配图 + 图文成品 ZIP + 素材合规选源/成片闸
- **v1.9**：短视频半自动 + 商用 BGM + 人审导出
- **v2.0+**：A/B、渠道归因、发布效果回流、Multi-Agent（与原「创作效果闭环」合并评估）

### 3.2 各版本刻意砍掉、仍未做

- 商机审批流程（v0.8 P2-06）
- 线索智能查重/合并；AI 赢单预测；智能培育邮件全链路
- 工商真实 Provider、决策链图谱 UI（仅有 stub）
- 评分/公海/BANT 等完整配置台（多为 API；分配规则 UI 已在 v1.2 补上）

### 3.3 SRS「暂不包含 / 远期」

- 小红书/抖音官方自动发布
- 计费与支付
- 向量 RAG（现为关键词检索）
- 微信一键登录 / 原生小程序包（当前以 H5 为准）
- Twilio 通话等
- 复杂 CPQ（BOM/约束引擎）、爬虫抓取平台、租户向公共招标池投稿
- 规格维度矩阵驱动 SKU（v1.4 P2）

### 3.4 运维侧（能力文档有，不等于产品功能缺口）

- 生产部署、真实微信对接、备案后的 L4 验收 —— 依赖环境而非代码版本线
