## 6. 风险与兼容性

1. **勿建第二套附件表**：Lead PRD 旧稿 053 已废止。
2. **contact_role 同名异义**：前后端文案必须区分「组织角色」vs「商机参与角色」。
3. **tags 双轨**：P1 上规范表后，读接口需兼容 JSON 临时数据或一次性迁移脚本。
4. **赢单 Hook 幂等**：重复标记 won 不可重复累加 total_revenue。
5. **来源常量变更**：已有 deal.source 合法值保持兼容；仅补 Webhook。
6. **回归**：每阶段跑 `verify_deal_*` + `verify_crm_23_*` + `verify_crm_numbering` + 本阶段 verify。
