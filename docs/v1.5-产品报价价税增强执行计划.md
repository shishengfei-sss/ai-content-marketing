## 0. 范围与决策（锁定）

### 0.1 三类交付

1. **产品** — `default_tax_rate` + `price_includes_tax`；表单参考换算；导入两列  
2. **报价** — 行级税字段；表单/详情三合计；头折摊入行后再计税  
3. **转单 / 订单** — 共用 `tax_engine`；转单复制含尾差后税额  

### 0.2 关键决策

| ID | 决策 | 选择 |
|----|------|------|
| D1 | 行未税 | `round(未税单价×数量×(1−行折%), 2)` |
| D2 | 行税额 | `round(行未税×税率/100, 2)`，每行独立 |
| D3 | 行价税 | 行未税 + 行税额 |
| D4 | 整单 | 总未税=Σ行未税；总税额=Σ行税；价税合计=二者之和；保存断言平衡 |
| D5 | 头折 | **先按行未税占比摊入各行**（末行吃未税分摊尾差），再计税；禁止只改总未税 |
| D6 | 税额尾差 | `\|exact_tax−Σ行税\|==0.01` → 差额写入最后一档有税行的 `tax_amount` |
| D7 | exact_tax | 单/多税率：`round(Σ(行未税×税率/100), 2)`（中间不按行 round） |
| D8 | 持久化 | `line_total`/`amount`/`total_amount`=未税；`tax_amount` 可被尾差改写 |
| D9 | 看板 | P0 **不改**统计公式；文案可标「未税」（见下文 §6） |
