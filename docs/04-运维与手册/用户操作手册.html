智营获客 · 用户操作手册

面向最终用户的功能操作指引。覆盖 v1.3 全部模块，逐条给出 新增 / 查看 / 编辑 / 删除 等具体操作步骤。

开发运维请看 docs/04-运维与手册/操作手册.md；产品规格见 docs/00-总览/需求规格.md。

市场运营 / 编辑AI 创作、活动、知识库、线索只读+新建
销售 sales线索/客户/任务（本人）、跟进、转化、导入
销售经理销售全部 + 团队/地区视图、分配、全量报表
企业管理员 admin本企业全功能 + 成员/角色/设置
平台运营 platform_admin企业管理、账号、公共知识库（仅 Web）

一个手机号可加入多家公司，登录后先选公司，数据随公司隔离。您只能看到有权限的数据。

① 登录与账号

所有操作的起点：登录、选公司、个人设置。

登录
  1. 打开 Web（默认 http://localhost:5173）或 H5（默认 http://localhost:5174）。
  2. 进入 /login（H5 为 #/pages/login/login），用手机号登录。
  3. 验证码：开发 / UAT 环境固定为 1111（真实短信接入前均为 Mock）。
  4. 加入多家公司时，按提示选择当前公司。
切换公司 / 设置
  1. 顶部或设置菜单点切换公司，选目标公司后菜单与数据随之切换。
  2. 账号：改密码、查看所属公司与角色。
  3. AI 模型：填自有 LLM Key → 测试连接 → 保存；不填则用平台额度。
  4. 权限菜单：角色不同可见菜单不同（销售看不到平台管理）。
找回密码
  1. 登录页点「忘记密码」。
  2. 输入手机号收验证码（Mock 1111）。
  3. 校验通过后设置新密码。
禁用 / 退出
  1. 账号禁用由平台运营在 /admin 操作（见平台后台章）。
  2. Web / H5 右上角头像可退出登录。
工作台(scope)：顶部可在 本人 / 全公司 间切换（有权限时才出现「全公司」），看板数字与列表实时一致。

② AI 创作

通用营销顾问 + 9 型人格自动适配，无需手动切行业/助手。支持公众号 / 小红书 / 抖音多形态内容。

新建会话 / 创作
  1. 进入「创作」页，左侧为历史会话列表，点「新建会话」。
  2. 在对话框描述需求（题材、平台、风格、要点）。
  3. 系统先出方案（不扣额度）→ 您确认后生成正文（成功扣 1 次额度）。
  4. 生成过程流式(SSE)实时输出；可多轮追问。
查看 / 恢复会话
  1. 左侧列表点任意历史会话即可恢复上下文（长期记忆，关掉再来还在）。
  2. 遇到异常会脱敏；可「会话恢复」回到上一稳定节点。
改稿 / 合规
  1. 敏感词 / 合规问题触发自检：通过 / 提醒 / 拦截。
  2. 点「合规改稿」一键按规则重写；或手动在输入框要求修改。
  3. 视频时长等参数可在创作选项中配置（v1.1 起）。
发布 / 导出 / 删除
  1. 公众号：Mock 发布（开发）或真实发布（需备案服务号）。
  2. 小红书 / 抖音：当前为导出内容（官方自动发布为远期）。
  3. 活动关联：把内容关联到营销活动（campaign_contents）。
  4. 删除：在历史会话行尾「⋯」可删除会话 / 清空内容库。
安全规则：AI 不会在您未确认时自动发布；被问「提示词 / 系统规则」只答「我不回答。」这是正常保护，不是故障。

③ 营销活动 Campaigns

市场运营组织内容、线索、任务的容器，可统计活动产出。

新增活动
  1. 「营销活动」→ 新建，填名称、时间、目标、关联渠道。
  2. 保存后进入活动详情。
关联内容 / 线索 / 任务
  1. 活动详情内可绑定已生成内容、从线索列表拉入线索、建任务。
  2. 创作页生成内容时可选择关联到本活动。
查看效果
  1. 活动页查看关联内容数、线索数、转化等（活动 ROI 为后续版本能力）。
编辑 / 删除
  1. 活动行尾「编辑」改信息；「删除」移除（关联数据不随删）。

④ 线索 Leads

获客入口：从创作、导入、活动、招标认领进入，转化为客户 / 商机。

新增线索
  1. 线索列表点「新建线索」。
  2. 填公司名称、联系人、手机（必填）等字段。
  3. 地区用省 / 市 / 区级联选择。
  4. 保存即生成线索（owner 为当前用户）。
查看 / 筛选
  1. 列表支持高级筛选（行业、地区、状态、负责人、评分等）。
  2. 常用筛选可保存视图并钉到侧栏。
  3. 点行进入线索详情（跟进、任务、关联客户）。
编辑 / 补充
  1. 详情页「编辑」改字段；可加标签、评分、分配负责人。
  2. 进入公海或回收由分配规则 / 管理员操作。
转化客户
  1. 点「转化为客户」，系统去重 / 合并同名客户。
  2. 可选联动建商机；转化时填 BANT（预算/授权/需求/时间）评估，建议金额。
批量导入
  1. 列表「导入」→ 下载模板 → 字段映射 → 预览 → 执行。
  2. 支持 CSV / XLSX；按「公司+联系人+手机」去重（skip / update）。
删除 / 通知
  1. 行尾「⋯」可删线索（需权限；删除不删已转化客户）。
  2. 右上角铃铛提醒分配、到期、待跟进等事件。

⑤ 客户 Customers

转化后的企业主体，承载 360 视图与全生命周期。

新增客户
  1. 通常由线索转化自动建；也可在客户列表手动「新建」。
  2. 填公司名、行业、规模、地址等。
360 视图
  1. 客户详情汇聚联系人、跟进、商机、订单、回款、生命周期阶段。
  2. 列表支持导出（v0.9 起）。
编辑 / 标签
  1. 「编辑」改资料；可加标签分组、维护多地址。
  2. 维护生命周期阶段、培育动作、UTM 来源。
删除 / 合并
  1. 重复客户在转化时合并；手动删除需 admin 权限。
  2. 删除客户会连带提示其下未结商机（谨慎）。

⑥ 联系人 Contacts

客户下的具体人，随客户继承数据范围。

新增
  1. 客户详情 → 联系人 → 新建，填姓名、职位、手机、邮箱。
查看
  1. 列表 / 客户 360 内查看；支持搜索。
编辑
  1. 行尾「编辑」改联系信息；可设为主要联系人。
删除
  1. 「删除」移除单个联系人（不删客户）。
联系人批量导入为远期能力；当前随客户 / 线索导入带入。

⑦ 跟进与任务 Tasks

每条线索 / 客户都可建跟进与任务，驱动销售动作。

写跟进 / 建任务
  1. 线索 / 客户详情点「写跟进」记录；点「建任务」设负责人、截止日、内容。
查看
  1. 工作台 / 任务列表按「我负责的 / 我创建的 / 团队」查看。
编辑 / 完成
  1. 任务详情改内容、改期、转派；完成后点「标记完成」。
删除
  1. 行尾「删除」移除任务（已完成也可删）。

⑧ 商机 Deals

销售管道核心。状态机 open → won / lost / abandoned。

新增商机
  1. 线索转化时联动建，或客户 / 商机列表「新建」。
  2. 填名称、金额、预计成交日、阶段（带概率）。
看板 / 详情
  1. 销售管道看板拖拽阶段；点卡片进详情。
  2. 详情含跟进、附件、明细、团队、漏斗、预测、赢/输。
编辑 / 克隆
  1. 「编辑」改金额 / 阶段 / 负责人；明细行可增删产品。
  2. 「克隆」快速复制相似商机；支持批量操作。
推进 / 赢输 / 转报价
  1. 拖到 won 标记赢单；lost / abandoned 标记丢单（可填原因）。
  2. 商机明细可一键生成报价单。
删除 / 作废
  1. 行尾「删除」移除商机；已赢单需先置回 open 再删（视权限）。
当前无商机审批流程（v0.8 已砍），赢单后直接进入报价 / 合同。超时、预测、阶段停留报表在运营域。

⑨ 产品与价目 Products

报价 / 订单的基础主数据；支持分类、SKU、价目、CPQ 开关。

新增产品
  1. 「产品」→ 新建，填名称、分类、单位、SKU、标准价。
  2. 启用 CPQ 的产品勾选 cpq_enabled 并配参数价差。
查看
  1. 产品列表 / 分类树查看；价目见 price_books。
编辑 / 分类
  1. 「编辑」改资料；维护产品分类与 SKU。
  2. 价目扩展写入 price_books（禁止平行价目主数据）。
删除
  1. 未用于报价 / 订单的产品可删；已引用者先解绑。

⑩ 报价与轻量 CPQ

v1.3 轻量 CPQ：按参数计价，结果写入现有报价单 quotes。仅 Web。

新建报价
  1. 从商机 / 订单 / 合同任一入口「生成报价」。
  2. 选客户、产品行、税率；或启用 CPQ 选参数实时计价。
查看 / 计算
  1. 报价详情看明细、金额、毛利；CPQ 实时算价 POST /crm/cpq/calculate。
  2. 毛利红线低于阈值时弹确认。
编辑 / PDF
  1. 「编辑」改行、折扣、税率；可复制历史报价。
  2. 「生成 PDF」（异步）；AI 需求解析需人审后生效。
转订单 / 合同 / 删除
  1. 一键转订单或合同。
  2. 行尾「删除」移除报价（未转单时可删）。
  3. 商机 / 线索页可唤起 CPQ。
复杂 CPQ（BOM / 约束引擎）、促销动态定价、AI 全自动报价为远期能力。

⑪ 合同 Contracts

基于模板生成，一份合同可生成多个订单。

新建合同
  1. 「合同」→ 新建，选模板，关联客户 / 报价 / 订单。
  2. 填条款、金额、起止日。
查看
  1. 合同列表 / 详情看状态、关联订单、续约附件。
修订 / 续约
  1. 「修订」生成新版本（v1.0）；「续约附件」追加。
  2. 「生成订单」从合同拉出订单（一对多）。
删除 / 作废
  1. 行尾「删除」移除合同（已生成订单者视权限处理）。

⑫ 订单 Orders

四种生成路径，支持审批、税率、发货、发票、退款。H5 可做订单操作。

新建订单（四路径）
  1. 商机 → 订单
  2. 报价 → 订单
  3. 合同 → 订单
  4. 报价 → 合同 → 订单

选路径后填明细行与税率。

查看 / 查询
  1. 订单列表支持高级查询；详情看明细、状态、关联回款。
审批 / 发货 / 发票
  1. 按金额规则可选审批。
  2. 「发货」登记发货；「发票」开具（v1.0）。
  3. 「修订」改订单（v1.0）。
退款 / 删除
  1. 「退款」走退款流程（有退款 Tab）。
  2. 未发货 / 未回款订单可删（视权限）。
渠道 ROI 按渠道统计投放回报（v1.0）。

⑬ 回款与发票 Payments / Invoices

资金闭环：回款计划 / 实际 / 冲销，发票核销。

新建回款计划
  1. 订单 / 回款页「新建回款计划」，填期次、金额、到期日。
登记实际 / 确认
  1. 计划行「登记实际回款」填金额与日期；「确认」入账。
  2. 错误可「冲销」。
发票核销
  1. 「发票」Tab 查看 / 核销发票（v1.2）。
删除
  1. 未确认回款可删；已确认需冲销后调整。

⑭ 招标线索 Tender（v1.3，仅 Web）

平台维护公共招标池，您的公司按 ICP 匹配，认领后进入线索。不自动建商机。

查看匹配池 L2
  1. 「招标线索」查看平台公共池(L1)经 ICP 五维加权打分后的匹配池(L2)，按匹配度排序。
认领 claim
  1. 对感兴趣标的点 claim：仅写入本公司的线索（状态 pending/valid/invalid/expired）。
  2. 后续像普通线索一样跟进、转化。
效果看板
  1. 查看认领转化情况（W11–12 试点 UAT 可选）。
平台维护 L1
  1. 仅 platform_admin 维护公共池（手工 / Excel / 附件 AI 人审）。
  2. 租户不能投稿，系统无爬虫。

⑮ 运营报表与提醒

v1.2 起：交易报表、到期提醒、分配规则、阶段停留。

交易报表
  1. 查看路径占比、回款率、账龄、负责人业绩。
  2. 阶段停留报表看商机各阶段时长。
到期提醒
  1. 工作台展示回款 / 合同到期提醒。
分配规则
  1. 「设置」中配置线索 / 客户自动分配规则（v1.2 起有 UI）。
发票 / 退款 Tab
  1. 订单详情查看发票核销、退款 Tab。

⑯ 平台后台 /admin（platform_admin，仅 Web）

平台运营专用，管理租户、账号、公共知识库与平台 AI。

企业管理
  1. 租户列表查看所有企业；进租户看成员。
  2. 转移管理员：一换一操作。
账号管理
  1. Membership 汇总；设 / 取消 platform_admin。
  2. 禁用、重置账号。
  3. 删账号不删租户（仅移除成员身份）。
公共知识库 / 平台 AI
  1. 维护平台级知识库（租户优先于平台 KB）。
  2. 配置平台默认 AI 额度 / Key。
招标池维护
  1. 在招标线索 L1 手工 / Excel / 附件 AI 人审录入。
