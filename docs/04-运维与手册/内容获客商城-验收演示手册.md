## 6. 建议走的 20 分钟剧本

对照 [开箱标准 §6](../02-执行计划/内容获客商城-开箱即用交付标准.md)。

| 步 | 谁 | 动作 | 成功画面 |
|----|-----|------|----------|
| 1 | 平台 | 超管登录 → [商家列表](http://localhost:5173/admin/shop/merchants) | 能看到经营中 / 审核中 / 暂停 / 清退 |
| 2 | 平台 | 打开一条审核中申请 | 待审详情可点（不必再审一遍） |
| 3 | 商家 | `13900000099` → [看板](http://localhost:5173/shop/overview) · [商品](http://localhost:5173/shop/products) | 看板有数；三类在售；草稿不可售 |
| 4 | 买家 | [店首页](#51-主商家验收必用) → 点课 → 确认支付（Mock） | 已购出现新权益 |
| 4b | 买家 | （备选）直接开 [已购](#51-主商家验收必用) | 已购出现演示课 |
| 5 | 买家 | 点「继续学」进课时目录 / 播放 | 履约成功 |
| 6 | 买家或商家 | 已付单申请退款 | 权益不可再学 |
| 7 | 买家 | （可选）[领权链接](#51-主商家验收必用) | 领权页可点 |
| 8 | 平台 / 商家 | [订阅台账](http://localhost:5173/admin/shop/subscriptions) / [商家套餐](http://localhost:5173/shop/subscription) | 基础版可读 |

任一步因缺陷无法继续且无备选 → **未达交付**。步 4 备选：商家 [订单列表](http://localhost:5173/shop/orders) 已能看到种子写入的已付 / 待付单。

## 8. 验收时不要当成故障

| 现象 | 说明 | 是否挡演示 |
|------|------|------------|
| 审批 / 导出没有短信、站内信 | 本批豁免 | 否 |
| 支付不是真微信、没有跳转收银台 | Mock 档，点确认即成功 | 否 |
| 买家「已封禁」Tab 是空的 | Phase 1 未落库，恒「正常」 | 否 |
| 没有购物车、SKU、物流、扫码枪 | 范围外 / Phase 2 | 否 |
| 结算是人工确认 + CSV，不是银行打款 / PDF | 已知范围 | 否 |
| 错密码有中文「手机号或密码错误」 | 预期；白屏才是问题 | — |

无 P0/P1 级「演示必现」项。真机微信 / 抖店另签，不阻塞本手册。

## 9. 常见卡住

| 现象 | 处理 |
|------|------|
| health 不通 / 页面仍旧 | `.\scripts\restart-api.ps1` 后强刷（Windows 热重载常假活） |
| 8003 / 5173 / 5174 占用 | 关掉占用进程再起；API 脚本会清 8002/8003 |
| 买家已购空白 | 链接须带 `tenant_id` 与 `openid=demo_buyer_paid`；先跑种子 |
| 登录 401 | 核对本手册账号表；超管 / 商家入口不要混 |
| 支付不成功 | 不要把 `WECHAT_PAY_MOCK` 关掉；默认 stub + Mock |
