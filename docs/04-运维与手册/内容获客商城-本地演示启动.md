## 2. 启动（≤10 步）

在仓库根目录打开 PowerShell。

**1. 升库 + 种子**（可重复；再跑不炸）

开箱最小集：

```powershell
.\scripts\start-shop-demo.ps1
```

验收量级（4 家经营中商家，每家 30～50 商品/订单）：

```powershell
.\scripts\start-shop-demo.ps1 -FullVolume
```

重建量级数据（不影响开箱最小集课/DEMO 订单）：

```powershell
.\scripts\start-shop-demo.ps1 -FullVolume -ResetDemo
```

等价分步：

```powershell
cd e:\ai-content-marketing\apps\api
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe tests\seed_shop_demo.py
```

验收列表造数（4 家经营中，每家 30～50 商品/订单）：

```powershell
cd e:\ai-content-marketing\apps\api
.\.venv\Scripts\python.exe tests\seed_shop_demo_full.py
```

**2. 启动 API**（另开窗口；Windows 须硬起，不要假设 `--reload` 已吃到新代码）

```powershell
cd e:\ai-content-marketing
.\scripts\restart-api.ps1
```

成功：浏览器打开 [http://127.0.0.1:8003/health](http://127.0.0.1:8003/health) 返回 ok。

**3. 启动 Web**（另开窗口；已在 5173 跑着可跳过）

```powershell
cd e:\ai-content-marketing\apps\web
npm run dev
```

成功：打开 [http://localhost:5173/login](http://localhost:5173/login)。

**4. 启动买家 H5**（另开窗口）

```powershell
cd e:\ai-content-marketing\apps\mp
npm run dev:h5
```

成功：打开 [http://localhost:5174](http://localhost:5174)（建议 F12 手机模式）。买家进店用种子打印的 **已购 / 领权** 链接，不要用智营员工登录页。

**5. 用 §0 三个号冒烟登录**：超管、经营中商家、已购买家链接。

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| 端口 8003 / 5173 / 5174 占用 | 关掉占用进程；API 用 `restart-api.ps1` 会清 8002/8003 |
| 种子 skip / 重复 | 默认可再跑；要重建演示目录加 `--reset-demo` |
| 支付不成功 | 确认未把 `WECHAT_PAY_MOCK` 改成关；默认 stub + Mock=1 |
| 改了 API 页面仍旧 | Windows 热重载常假活，跑 `scripts/restart-api.ps1` 后再刷页面 |
| health 不通 | 先看 API 窗口是否报错；`.venv` 是否在 `apps/api` |
| 登录 401 | 核对本页账号表；错密应提示「手机号或密码错误」（非白屏） |
| 买家已购空白 | 链接必须带 `tenant_id` 与 `openid=demo_buyer_paid`；先跑种子 |
| 超管进了商家壳 | 用 `/admin/login`，不要用 `/login` |
