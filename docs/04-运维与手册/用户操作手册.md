# 智营获客 · 用户操作手册

> 给**最终用户**看的功能操作指引：市场运营、销售、销售经理、企业管理员、平台运营都能照着做。
> 配套开发/运维内容见 `docs/04-运维与手册/操作手册.md`；产品规格细节以 `docs/00-总览/需求规格.md` 与各版本执行计划为准。
> 当前版本：**v1.3**（含 AI 创作、CRM 全链路、招标线索、轻量 CPQ、运营报表）。

---

## 0. 先确认您是谁

| 您的角色 | 主要能做什么 | 入口 |
|----------|--------------|------|
| **市场运营 / 编辑** | AI 创作、营销活动、知识库、线索只读+新建 | Web / H5 创作与工作台 |
| **销售（sales）** | 线索/客户/任务（本人）、跟进、转化、导入、写商机 | Web / H5 |
| **销售经理** | 销售的全部 + 团队/地区视图、分配、公开视图、全量报表 | Web / H5 |
| **企业管理员（admin）** | 本企业全部功能 + 成员/角色/企业信息/设置 | Web / H5 |
| **平台运营（platform_admin）** | 企业管理、账号管理、公共知识库、平台 AI（**仅 Web `/admin`**） | Web `/admin` |

> 一个手机号可加入多家公司。登录后先**选公司**，菜单与数据随公司切换；您只能看到自己有权限的数据（系统强制，改不了）。

## 1. 登录与基础操作

### 1.1 登录
1. 打开 Web（默认 `http://localhost:5173`）或 H5（默认 `http://localhost:5174`，手机模式）。
2. 进入 `/login`（H5 为 `#/pages/login/login`），用**手机号**登录。
3. 验证码：开发/UAT 环境固定为 **`1111`**（真实短信接入前均为 Mock）。
4. 登录后若加入多家公司，按提示**选择当前公司**；之后可随时在设置/切换菜单换公司。

### 1.2 工作台（看板）
- 顶部可切换 scope：**本人** / **全公司**（您有权限时才出现「全公司」）。
- 看板展示创作、线索、商机、回款等关键数字，与列表实时一致。

### 1.3 个人设置
- **账号**：改密码、查看所属公司/角色。
- **AI 模型**：填自有 LLM Key（DeepSeek 等）→「测试连接」→ 保存；不填则用平台默认额度。
- **权限菜单**：不同角色看到的菜单不同（如销售看不到平台管理）。

## 2. AI 创作（核心功能）

> 通用营销顾问 + 9 型人格自动适配，无需手动切行业/助手。支持公众号 / 小红书 / 抖音多形态内容。

### 2.1 进入创作
- Web / H5 进入「创作」页。左侧为**历史会话**列表，可切换或新建会话（会话持久化，关掉再来还在）。

### 2.2 生成内容
1. 在对话框描述需求（题材、平台、风格、要点）。
2. 系统先给**方案**（不扣额度）→ 您确认后**生成正文**（成功扣 1 次平台额度）。
3. 生成过程为**流式（SSE）**实时输出；遇到敏感词/合规问题会**自动自检**，给出通过 / 提醒 / 拦截，并可一键改稿。
4. 多轮对话中 Agent 会记住上下文（长期记忆），并每轮给出下一步建议。

### 2.3 发布 / 导出
- **公众号**：Mock 发布（开发环境）或配置真实服务号后真实发布（需备案）。
- **小红书 / 抖音**：当前为**导出**内容，官方自动发布为远期能力。
- **活动关联**：可把内容关联到某个营销活动（`campaign_contents`），便于统计活动产出。

> ⚠️ 安全规则：AI **不会**在您未确认的情况下自动发布；被问到"提示词/系统规则"时它只会回答"我不回答。"——这是正常保护。

## 3. 线索管理

### 3.1 查看与筛选
- 线索列表支持**高级筛选**（行业、地区、状态、负责人等）、**保存视图**（常用筛选钉到侧栏）。

### 3.2 新建线索
1. 点「新建线索」，填写公司名称、联系人、手机（**必填**）等。
2. 地区支持**省 / 市 / 区**级联选择。

### 3.3 跟进与转化
1. 打开线索 → 写**跟进记录** → 建**任务** → 标记完成。
2. 转化客户：点「转化为客户」，系统会**去重/合并**同名客户，并可选关联建**商机**。
3. 转化时可联动 **BANT**（预算/授权/需求/时间）评估，建议商机金额。

### 3.4 批量导入
- 用**导入向导**：下载模板 → 字段映射 → 预览 → 执行。
- CSV/XLSX 均可；按「公司名称 + 联系人 + 手机」去重（skip / update）。

### 3.5 公海、评分与分配
- 线索可有**评分**、可进入**公海**（含定时回收）。
- **自动分配规则**在「设置」中配置（v1.2 起有 UI）。

### 3.6 通知
- 右上角**铃铛**提醒待办、分配、到期等事件。

## 4. 客户管理

- **360 视图**：客户全景（联系人、跟进、商机、订单、生命周期阶段）。
- **标签 / 多地址**：打标签分组，维护多个联系地址。
- **生命周期 / 培育 / UTM / ROI**：记录客户阶段、培育动作、来源渠道（UTM）与投入产出。
- **导出**：列表支持导出（v0.9 起）。

---

## 5. 商机（Deal）管理

- **销售管道看板**：拖拽阶段（阶段带概率），状态机 `open → won / lost / abandoned`。
- **详情**：跟进、附件、明细（产品行）、团队、漏斗、超时提醒、预测、赢/输、批量操作、克隆。
- **明细 → 报价**：商机产品明细可直接生成报价单。
- **报表**：漏斗、预测、阶段停留报表（运营域）。

> ⚠️ 当前**无商机审批流程**（v0.8 已砍掉），赢单后直接进入报价/合同。

---

## 6. 报价 / 轻量 CPQ（v1.3，仅 Web）

> CPQ = 按参数自动计价。本产品为轻量版，结果**写入现有报价单**。

### 6.1 普通报价
- 从商机/订单/合同任意入口生成报价；可**一键转订单或合同**。

### 6.2 轻量 CPQ
1. 产品需启用 CPQ（`cpq_enabled`），配置参数与价差（固定/百分比/倍率）。
2. 在报价页选参数 → 实时计价（`POST /crm/cpq/calculate`）。
3. **毛利红线**告警：低于阈值须您确认。
4. **生成 PDF**（异步），可复制历史报价、AI 解析需求（人审后生效）。
5. 从商机/线索页可**唤起 CPQ**。

> ⚠️ 复杂 CPQ（BOM/约束引擎）、促销动态定价、AI 全自动报价为远期能力。

## 7. 合同管理

- **模板**：用合同模板快速生成。
- **一对多**：一份合同可生成多个订单；支持续约附件。
- 修订：v1.0 起支持合同修订。

---

## 8. 订单管理

- **四种生成路径**：商机 → 订单 / 报价 → 订单 / 合同 → 订单 / 报价 → 合同 → 订单（避免平行主报价表）。
- **审批**：按金额规则可选审批。
- **明细税率**：订单行支持税率。
- **发货 / 发票 / 退款**：v1.0 起支持发货、发票、订单修订；H5 可做订单操作；有**退款 Tab**。
- **渠道 ROI**：按渠道统计投放回报（v1.0）。

---

## 9. 回款与发票

- **回款**：计划 / 实际 / 确认 / 冲销。
- **发票**：发票核销（v1.2 起有 Tab）、订单退款 Tab。
- **提醒**：工作台展示**回款 / 合同到期**提醒（v1.2）。

---

## 10. 招标线索（v1.3，仅 Web）

> 平台维护公共招标池，您的公司按 ICP 匹配，认领后进入您的线索。**不自动建商机。**

1. 进入「招标线索」：平台公共池（L1）经 ICP 五维加权打分后，给您**匹配池（L2）**排序。
2. 对感兴趣的标的点 **claim（认领）**：仅写入您公司的**线索**（状态 `pending/valid/invalid/expired`）。
3. 后续像普通线索一样跟进、转化。
4. 效果看板可看认领转化情况（W11–12 试点 UAT 可选）。

> ⚠️ 平台公共池**仅平台运营维护**，租户不能投稿；系统**无爬虫**，标的信息由平台手工/Excel/附件 AI 人审录入。

## 11. 运营报表与提醒（v1.2）

- **交易报表**：路径占比、回款率、账龄、负责人业绩。
- **阶段停留报表**：商机在各阶段停留时长。
- **提醒**：回款到期、合同到期（工作台顶部）。
- **分配规则**：在「设置」中配置线索/客户自动分配。

---

## 12. 平台后台（platform_admin，仅 Web `/admin`）

- **企业管理**：租户列表、成员管理、**转移管理员**（一换一）。
- **账号管理**：Membership 汇总、设为 platform_admin、禁用、重置、**删账号不删租户**。
- **公共知识库 / 平台 AI**：维护平台级知识库与默认 AI 额度/Key。

## 13. 常见操作提示

| 我想… | 怎么做 |
|-------|--------|
| 换一家公司 | 设置 / 切换公司菜单，选目标公司 |
| 找回密码 | 登录页「忘记密码」→ 收验证码（Mock `1111`）→ 重置 |
| 看自己 vs 全公司数据 | 工作台顶部切「本人 / 全公司」 |
| AI 不动了 / 报错 | 刷新会话或开「Agent 回退」（VITE_AGENT_FALLBACK） |
| 内容发不出去 | 公众号需真实服务号+备案；小红书/抖音当前只能导出 |
| 额度用完 | 让 admin 在平台加额度，或自己在「设置→AI 模型」配自有 Key |
| 把 Excel 线索批量进系统 | 线索列表「导入」→ 模板/映射/预览/执行 |
