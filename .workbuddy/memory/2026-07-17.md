   - 左编辑 / 右 A4 实时预览；价格瀑布引擎：单价×阶梯(按量)×客户等级×时效加价=折后单价
   - 一键 打印/导出 PDF（print CSS 隐藏编辑区）；支持草稿水印、导出/导入 JSON
   - 预置示例：苏州汽车零部件采购「工业烘箱 NXO-2000 Pro」订单，3 行产品，报价总计 **¥286,284.37**（呼应梅施 NX-2000 Pro ¥286,000）
   - `?doc=1` 模式仅显示报价单（干净可打印）

### 关键结论
- 报价单 = 模板 + 数据绑定 + 定价引擎，不是写死页面
- 定价一定要用「价格瀑布分层」建模（每层可审计），客户等级/阶梯/区域运费/加急对应我们的方案
- 友商市场空白：中型制造企业「获客→报价」一体化（SAP/纷享贵且重，订阅蜂/梅施不做获客）—— 这是我们方案「商机直接进 CPQ 自动填参」飞轮的机会
